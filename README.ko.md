# Language Learning Coach | 여행 A2를 위한 언어 코치

**다음 여행을 위해, 현재 실력에 맞는 가장 짧고 실용적인 경로로 검증 가능한 A2 기초를 다집니다.**

![기차역, 호텔, 식당을 거치는 여행 언어 학습 장면 일러스트](assets/readme/travel-hero.webp)

Language Learning Coach는 실제 과제, 신뢰할 수 있는 입력, 실용적인 표현, 능동적 인출, 상호작용, 집중 피드백, 지연 복습을 통해 학습하는 적응형 Codex Skill입니다.

프랑스어, 독일어, 이탈리아어, 스페인어, 포르투갈어, 한국어, 일본어, 아랍어, 영어처럼 학습 자료가 충분한 현대 언어를 여행 목적으로 배울 때 우선 적합하도록 설계했습니다. 학습 언어, 지역 변이, 문자 체계, 학습에 쓸 수 있는 시간, 실제로 해낼 수 있는 과제에 따라 수업 내용이 달라집니다.

> [!IMPORTANT]
> “여행 A2”는 이 프로젝트가 제안하는 훈련 경로이지, CEFR의 공식 하위 등급이나 자격증이 아닙니다. A2는 익숙하고 일상적인 상황에서 이루어지는 단순하고 직접적인 정보 교환을 다룹니다. CEFR에서는 여행 중 생길 법한 대부분의 상황에 대처하는 능력을 B1에 둡니다. 따라서 이 코치는 **흔하고 예측 가능한 여행 과제를 좀 더 자신 있게 수행하는 것**을 목표로 하며, 모든 여행 상황이나 긴급 상황을 부담 없이 처리할 수 있다고 약속하지 않습니다. 유럽 평의회의 [CEFR 전체 등급표](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)와 [말하기 능력 기술표](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)를 참고하세요.

> [!NOTE]
> 이 프로젝트는 Kazuma가 공개적으로 공유한 학습 실천에서 영감을 받은 독립 오픈소스 프로젝트입니다. Kazuma가 공식적으로 만들거나 승인한 프로젝트가 아니며, 제휴나 추천 관계도 없습니다.

## 기록을 채우기보다 여행을 준비합니다

![교통, 숙박, 식사, 길 찾기, 쇼핑, 의사소통 복구로 이루어진 여섯 가지 여행 훈련 영역](assets/readme/travel-scenarios.svg)

기본 여행 경로는 다음 여섯 가지 수행 목표에 집중합니다.

- **교통:** 표, 승강장, 시간, 경로, 변경 사항을 묻습니다.
- **숙박:** 체크인하고, 예약 정보를 확인하며, 간단한 문제를 설명합니다.
- **식사:** 주문하고, 선호를 밝히며, 후속 질문을 알아듣고, 결제합니다.
- **길 찾기:** 길을 묻고, 지형지물을 확인하며, 제대로 이해했는지 되묻습니다.
- **쇼핑:** 가격, 수량, 크기, 재고, 결제를 처리합니다.
- **의사소통 복구:** 반복해 달라, 천천히 말해 달라, 적어 달라, 가리켜 달라, 다른 말로 바꿔 달라고 요청합니다.

학습 중인 표현마다 내가 실제로 쓸 버전, 바꿔 넣을 자리, 예상 후속 질문, 대화 복구 표현을 함께 저장합니다. 목표는 고정된 여행 회화집을 외우는 것이 아니라, 세부 조건 하나가 달라져도 과제를 끝내는 것입니다.

심각한 의료·법률·출입국·안전 관련 긴급 상황은 A2만으로 혼자 안전하게 처리할 수 있는 상황처럼 제시하지 않습니다.

## 한 줄로 시작하기

```text
$language-learning-coach를 사용해 주세요. 일본어를 처음부터 배우고 있고, 매일 15분씩
공부할 수 있습니다. 일본 여행에서 기본적인 대화를 해내고 싶습니다.
```

학습할 언어를 말하지 않았다면 첫 응답에는 다음 문장만 표시됩니다.

```text
어떤 언어를 배우고 싶나요?
```

그 뒤로 코치는 한 번에 질문 하나만 합니다. 다음 수업이 실제로 달라질 때만 묻습니다. 긴 설문이나 일반적인 학습 일정표를 받는 대신 작은 과제부터 바로 시작합니다.

다음과 같이 시작할 수도 있습니다.

```text
$language-learning-coach를 사용해 주세요. 이집트 아랍어로 정중하게 부탁하는 법을
연습하고 싶습니다. 현지 구어와 현대 표준 아랍어를 구분해 주세요.
```

```text
$language-learning-coach를 사용해 주세요. 어제 하던 브라질 포르투갈어를 이어서
공부하고 싶습니다. 오늘은 5분밖에 없습니다.
```

## 가장 짧고 유용한 경로는 적응형입니다

![실제 여행 과제에서 신뢰할 수 있는 입력, 인출, 상호작용, 피드백, 지연 전이로 이어지는 여덟 단계 순환](assets/readme/adaptive-loop.svg)

말하기가 포함된 여행 목표라면 보통 다음 순서로 수업이 진행됩니다.

1. 실제 여행 과제 하나와 목표로 삼을 지역 변이를 정합니다.
2. 답을 보기 전에 출처 분류가 명시된 전체 음성 본보기를 듣습니다.
3. 의사소통 의도와 핵심 정보 하나를 파악합니다.
4. 바꿔 넣을 자리가 있는 전체 표현을 한 개에서 세 개 익힙니다.
5. 힌트가 하나씩 사라지는 동안 스스로 기억해 내고 바꾸어 말합니다.
6. 예상 후속 질문에 답하고, 필요하면 대화 복구 표현을 써서 짧은 상호작용을 마칩니다.
7. 과제 수행에 중요한 문제 한두 가지만 고친 뒤 곧바로 다시 해 봅니다.
8. 시간이 지난 뒤 장소, 시간, 사람, 물건, 조건 중 하나를 바꾸어 다시 시도합니다.

읽기나 쓰기만을 목표로 할 때, 접근성 지원이 필요할 때, 새로운 문자 체계를 배울 때, 성조·음높이·음장 대립이 있을 때, 굴절이 풍부할 때, 높임말이나 지역 변이 또는 양층언어 현상을 다룰 때는 순서가 달라집니다. 여행이 우선 경로이지만, 신뢰할 수 있는 자료가 있다면 업무, 시험, 읽기, 쓰기, 미디어, 계승어 목표도 지원합니다.

## 한 번의 미니 수업, 눈에 보이는 네 단계

![완전한 본보기 듣기, 과제 시도, 한 가지 집중 교정, 조건을 바꾼 재시도로 이어지는 네 장면](assets/readme/lesson-storyboard.svg)

1. **본보기:** 출처 분류가 명시된 표현 전체를 먼저 듣고, 필요할 때 글을 확인합니다.
2. **시도:** 매표소, 호텔 프런트, 식당, 상점, 길 찾기 과제 안에서 표현을 사용합니다.
3. **집중 피드백:** 대화의 흐름을 살리면서 과제 수행에 가장 큰 영향을 주는 문제만 고칩니다.
4. **재시도:** 곧바로 과제를 한 번 더 마친 뒤 조건 하나를 바꾸어, 베끼기가 아니라 인출이 작동하게 합니다.

AI 역할극은 유용한 모의 훈련입니다. 하지만 원어민, 자연스러운 말하기 속도, 주변 소음, 낯선 억양, 예측할 수 없는 실제 반응에 대처했다는 증거는 아닙니다.

## A2를 방향으로 삼고, 능력별 증거를 기록합니다

![듣기, 말하기 산출, 읽기, 쓰기, 상호작용, 발음이 도움받은 연습에서 독립 수행, 조건 변경, 지연 후 유지로 이어지는 과정](assets/readme/evidence-ladder.svg)

듣기, 말하기 산출, 읽기, 쓰기, 상호작용, 발음을 따로 추적합니다. 표현을 들었다고 해서 곧바로 말할 수 있다고 보지 않습니다. 소리 내어 읽는 것은 상호작용의 증거가 아니며, 같은 수업에서 성공했다고 해서 기억이 유지되었다고 보지 않습니다.

증거 단계는 다음과 같습니다.

```text
도움받아 수행 → 독립 수행 → 조건을 바꾼 전이 → 지연 후 유지
```

작업 공간에는 과제, 힌트 수준, 증거 환경, 결과, 날짜, 다음 복습 시점을 기록합니다. 실제 사람이나 현실 과제에서 확인한 결과는 증거를 강화할 수 있지만, 이 프로젝트는 A2 자격증을 발급하지 않습니다. 진행 속도는 학습 언어, 출발점, 연습 시간, 자료의 질, 그리고 수행이 조건 변화와 시간 간격을 견디는지에 따라 달라집니다.

## 음원 출처를 숨기지 않습니다

말하기 목표에서는 재생 가능한 음원이 있을 때 새 표현을 글로 확인하기 전에 먼저 듣습니다. 모든 본보기는 다음과 같이 분류합니다.

| 출처 분류 | 의미 | 근거로 사용할 수 있는 범위 |
|---|---|---|
| `native_official` | 목표 지역 변이의 원어민이 녹음한 공식 또는 기관 음원 | 출처가 실제로 다루는 자료에 대한 강한 본보기 |
| `native_traceable` | 화자와 출처를 추적할 수 있고, 지역 변이·맥락·사용역이 알맞은 원어민 음원 | 출처에 문서화된 범위 안에서의 본보기 |
| `tts` | 합성 음성 대체 수단임을 명확히 표시 | 초기 듣기와 예행연습. 원어민 본보기나 발음 능력의 증거는 아님 |
| `pending` | 신뢰할 수 있는 본보기가 아직 제공되지 않음 | 내용을 지어내지 않고 말하기 또는 발음 단계를 멈춤 |

로컬 WAV 파일은 전달하기 전에 구조를 검증합니다. 기술적으로 유효하다는 사실이 출처의 신뢰성, 올바른 지역 변이, 실제 재생 여부, 발음 평가를 대신하지는 않습니다.

## 설치

로컬 Skill을 지원하는 Codex와 내장 음원·작업 공간 검증기를 실행할 Python 3가 필요합니다. 음원 검증기는 기존 비압축 RIFF PCM WAV만 허용하므로 다른 형식은 먼저 변환해야 합니다. Git 방식으로 설치하려면 Git도 필요합니다.

### 내장 Skill 설치 도구

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

또는 저장소를 다운로드한 뒤 그 내용을 다음 경로에 복사할 수 있습니다.

```text
~/.codex/skills/language-learning-coach
```

설치 후 Codex가 Skill을 인식하도록 새 Codex 작업을 시작하세요.

## 언어에 따라 경로가 달라지는 방식

| 언어 또는 목표의 특성 | 적응 방식 |
|---|---|
| 성조, 음높이 악센트, 음장 또는 강세 대립 | 산출 전에 지각 대조를 연습하고, 이어서 문장 단위로 훈련합니다. |
| 새롭거나 복잡한 문자 체계 | 소리와 문자를 함께 익히며, 전사 표기를 단계적으로 줄이는 계획을 세웁니다. |
| 굴절이 풍부하거나 교착성이 강한 구조 | 전체 표현과 함께 어간·접사를 일찍 분석하고 통제된 산출을 연습합니다. |
| 사용역, 높임말, 방언 연속체 또는 양층언어 현상 | 각 표현에 대화 상대와의 관계, 지역, 사용 매체 정보를 연결합니다. |
| 읽기, 쓰기, 업무, 시험, 미디어 또는 계승어 목표 | 실제 목표에 맞게 기능별 비중과 증거 과제를 바꿉니다. |

위 예시는 고정된 지원 언어 목록이 아닙니다. 신뢰할 수 있는 음원, 사전, 문법 자료, 실제 용례 근거가 있다면 다른 현대 음성 언어나 문자 언어도 범위에 들어옵니다. 수어, 고전어, 인공어, 자료가 희소한 언어에는 이 Skill의 현재 범위를 넘어서는 전문 자료나 지도가 필요합니다.

## 로컬 학습 상태와 개인정보 보호

현재 작업 공간에 쓸 수 있다면 코치는 다음 파일을 관리할 수 있습니다.

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
├── function-map.md
└── progress.md
```

읽기 쉬운 이 Markdown 파일에는 수업에 필요한 목표와 제약, 학습 습관을 시작하는 계기, 맥락이 있는 표현, 음원 출처 분류, 능력별 증거, 기초 의사소통 기능의 학습 범위, 교정 내용, 예정된 복습을 저장합니다. 파일은 설치된 Skill 디렉터리가 아니라 사용자의 작업 공간에 남습니다. 내장 검증기는 구조와 내부 일관성만 확인하며, 기록된 학습 결과가 사실이라고 주장하지 않습니다.

이 저장소에는 원격 측정, 계정 연동, 백그라운드 서비스가 없습니다. 수업에 신뢰할 수 있는 언어 자료가 필요할 때 Codex와 사용자가 허용한 도구가 외부 출처에 접근할 수 있으며, 해당 제품의 개인정보 보호 규칙이 계속 적용됩니다.

## 학습법과 연구 근거

설계에는 Kazuma가 공개적으로 설명한 소리 우선 모방, 실용적인 표현, 능동 어휘, 실용 문법, 꾸준한 과제 중심 습관, 관심사 기반 입력이 반영되었습니다. 자세한 내용은 [학습법 요약과 일차 자료](references/kazuma-method.md)를 참고하세요.

이러한 실천을 하나의 과학적으로 검증된 체계로 취급하지는 않습니다. 이 Skill은 발음 지도, 정형화된 표현, 명시적 문법, 상호작용과 교정 피드백, 간격 학습과 인출, 의미 중심 입력, 자기조절에 관한 제2언어 습득 연구를 바탕으로 각 선택을 점검합니다. 자세한 내용은 [근거 매트릭스와 안전 원칙](references/evidence-and-guardrails.md)을 참고하세요.

이 README의 시각적 탐색 방식은 [byoungd/up](https://github.com/byoungd/up)의 언어 학습 부분을 참고했습니다. 이 저장소의 모든 문구와 시각 자료는 독창적으로 제작했으며, 해당 저장소의 사진이나 일러스트를 재사용하지 않았습니다.

## 기여
