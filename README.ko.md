# Language Learning Coach

언어 학습을 일회성 설명이 아닌 지속적인 훈련으로 바꾸는 적응형 Codex Skill입니다. 신뢰할 수 있는 입력, 실용적인 표현 묶음, 능동적 산출, 실제 상호작용, 집중 피드백, 지연 복습을 하나의 과정으로 연결합니다.

목표 언어, 변이, 표현 매체, 학습 목표와 학습자의 실제 수행에 따라 수업을 조정합니다. 신뢰할 수 있는 자료가 있다면 음성 언어와 문자 언어, 수어, 고전어, 인공어, 저자원 언어에 맞게 적응할 수 있습니다.

> [!IMPORTANT]
> 이 프로젝트는 Kazuma가 공개적으로 공유한 학습법에서 영감을 받은 독립 오픈소스 프로젝트입니다. Kazuma의 공식 프로젝트가 아니며, Kazuma의 허가·제휴·보증을 받지 않았습니다.

## 무엇이 다른가요?

많은 AI 언어 학습 세션은 일회성 대화로 끝납니다. Language Learning Coach는 지속적인 학습 과정으로 설계되었습니다.

- **추상적인 진도보다 실제 과제 우선:** 목표를 음식 주문이나 후속 질문에 답하기처럼 관찰 가능한 행동으로 바꿉니다.
- **실용적인 표현 묶음을 유연하게 활용:** 완성된 표현을 고정된 대본으로 외우는 대신 맥락, 응답 방식, 교체 가능한 슬롯과 함께 익힙니다.
- **설명보다 연습 우선:** 입력과 상호작용으로 시작한 뒤, 방금 사용한 표현에서 가치가 높은 문법 패턴 하나를 설명합니다.
- **연속 학습 일수보다 수행 증거:** 숙달 여부를 학습 시간이나 복습 카드 수가 아니라 힌트 없는 회상, 전이, 상호작용과 지연 후 수행으로 판단합니다.
- **언어별 적응:** 성조, 문자 체계, 복잡한 형태론, 사용역, 수어 공간과 역사적 전통에 따라 수업 설계를 바꿉니다.
- **지속적인 로컬 상태:** 학습 프로필, 표현 저장소, 수행 증거와 다음 복습 대기열을 읽기 쉬운 Markdown으로 관리할 수 있습니다.

## 핵심 기능

- 처음 시작할 때 정확히 하나의 질문으로 초기 설정을 시작합니다. **`你要学习什么语言？`**(“어떤 언어를 배우고 싶나요?”)
- 적응형 일일 수업, 5분 유지 학습, 심화 학습과 실전 복기 모드
- 신뢰할 수 있는 음원을 활용하고 도구의 한계를 솔직히 밝히는 듣기·발음 연습
- 손 동작과 비수지 요소를 포함하는, 영상 우선의 수어 학습 적응
- 실용 문법, 능동 어휘, 대화, 읽기, 쓰기와 시험 대비 훈련
- `new`부터 `retained`까지 여섯 가지 증거 상태를 사용하는 지연 인출 및 전이 점검
- 한 언어를 주력으로 두고 추가 언어를 유지 학습으로 순환하는 기본 운영 방식
- 고립된 단어 쌍이 아니라 ‘상황 → 표현’ 인출을 중심으로 구성하는 선택적 Anki 내보내기
- 저자원 언어나 민감한 언어를 위한 출처 검증과 명시적인 `needs_confirmation` 처리

## 요구 사항 및 설치

로컬 Skill을 지원하는 Codex가 필요합니다. 내장 설치 프로그램 방식에는 Python 3가 필요하고, Git clone 방식에는 Git이 필요합니다. 저장소를 다운로드해 복사하는 방식에는 Git이 필요하지 않습니다.

### 내장 Skill 설치 프로그램으로 설치

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git으로 설치

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

Git을 사용하지 않으려면 저장소를 다운로드한 뒤 그 내용을 다음 경로에 복사할 수도 있습니다.

```text
~/.codex/skills/language-learning-coach
```

설치 후 Codex가 Skill을 인식할 수 있도록 새 Codex 작업을 시작하세요.

## 빠른 시작

Skill을 직접 호출하세요.

```text
$language-learning-coach를 사용해 언어 학습을 도와주세요.
```

학습할 언어를 지정하지 않았다면 첫 번째 응답에는 다음 문장만 표시됩니다.

```text
你要学习什么语言？
```

구체적인 목표와 함께 시작할 수도 있습니다.

```text
$language-learning-coach를 사용해 주세요. 저는 일본어를 처음부터 배우고
있고 하루에 15분을 쓸 수 있습니다. 일본 여행에서 기본적인 대화를 하고 싶어요.
```

```text
$language-learning-coach를 사용해 주세요. 미국 수어 커뮤니티 행사에서
자기소개를 할 수 있게 도와주세요. 짧은 영상을 보고 녹화할 수 있습니다.
```

```text
$language-learning-coach를 사용해 주세요. 어제 하던 브라질 포르투갈어
수업을 계속하고 싶습니다. 오늘은 5분밖에 없어요.
```

코치는 다음 수업을 바꾸는 데 필요한 정보만 질문한 뒤, 긴 설문이나 일반적인 학습 계획을 제시하는 대신 작고 실제적인 과제를 바로 시작합니다.

## 수업 적응 방식

| 언어 또는 목표의 특성 | 적응 방식 |
|---|---|
| 성조, 음높이 악센트, 음장 또는 강세 대립 | 산출 전에 지각 대조를 하고, 이어서 문장 단위로 연습합니다. |
| 새롭거나 복잡한 문자 체계 | 소리와 문자를 함께 익히며, 전사 표기는 단계적으로 줄이는 계획을 세웁니다. |
| 풍부한 굴절 또는 교착 구조 | 완전한 표현 묶음과 함께 어간·접사를 일찍 분석하고 통제된 산출을 연습합니다. |
| 사용역, 높임말, 방언 연속체 또는 양층언어 | 각 표현에 관계, 지역과 매체 정보를 연결합니다. |
| 수어 | 발음 연습을 신뢰할 수 있는 영상, 수어 공간, 움직임, 방향과 비수지 표지 훈련으로 대체합니다. |
| 고전어, 역사어 또는 전례 언어 | 텍스트 전통, 형태론, 말뭉치 증거와 명시된 발음 전통을 우선합니다. |
| 저자원 언어 또는 공동체의 주의가 필요한 언어 | 공동체나 기관의 출처를 우선하며, 불확실한 내용을 만들어 내지 않습니다. |
| 시험, 읽기, 쓰기, 업무, 여행 또는 계승어 목표 | 실제 목표에 맞게 기능별 비중과 평가 과제를 조정합니다. |

고정된 ‘지원 언어’ 목록은 없습니다. 지원 정도는 요청한 표현 매체와 이용 가능한 자료의 품질에 따라 달라지며, 검증할 수 없는 내용은 코치가 명확히 밝혀야 합니다.

## 학습 상태와 개인정보 보호

현재 작업 공간에 쓸 수 있다면 코치는 다음 파일을 관리할 수 있습니다.

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
└── progress.md
```

이 파일에는 목표와 제약, 맥락 및 출처가 포함된 표현, 관찰된 수행, 교정과 예정된 복습처럼 수업에 필요한 정보만 저장됩니다. 파일은 사용자의 작업 공간에 남으며, 설치된 Skill 디렉터리에는 기록되지 않습니다.

이 저장소에는 원격 측정, 계정 연동 또는 백그라운드 서비스가 없습니다. 다만 수업에 최신 정보나 신뢰할 수 있는 언어 자료가 필요할 때 Codex와 사용자가 허용한 도구가 외부 출처에 접근할 수 있으며, 해당 제품과 도구의 개인정보 보호 규칙이 계속 적용됩니다.

## 방법과 근거

수업은 다음 순환으로 진행됩니다.

```text
신뢰할 수 있는 입력 → 맥락이 있는 표현 묶음 → 지각과 모방 → 생성
→ 상호작용 → 집중 피드백 → 지연 인출
```

설계에는 Kazuma가 공개적으로 설명한 소리 우선 모방, 실용적인 표현, 능동 어휘, 실용 문법, 과제 중심의 꾸준한 습관과 관심사 기반 몰입이 반영되었습니다. 자세한 내용은 [학습법 요약과 일차 자료](references/kazuma-method.md)를 참고하세요.

이러한 실천법을 하나의 과학적으로 검증된 체계로 취급하지는 않습니다. 이 Skill은 발음 지도, 공식화된 표현, 명시적 문법, 상호작용과 교정 피드백, 간격 및 인출, 의미 중심 입력과 자기조절에 관한 제2언어 습득 연구를 바탕으로 각 선택을 점검합니다. 자세한 내용은 [근거 매트릭스와 안전 원칙](references/evidence-and-guardrails.md)을 참고하세요.

코치는 정해진 기간 안의 유창성, 원어민 같은 억양, 모든 언어에서 동일한 자료 품질을 보장하지 않습니다. 또한 연속 학습 일수, 학습 시간, 당일 성공 또는 Anki 정답률만으로 숙달을 판단하지 않습니다.
