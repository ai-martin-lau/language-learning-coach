# Language Learning Coach | 완전 초보 A2 언어 코치

**완전 초보부터 시작해 무료 음성 환경을 먼저 준비하고, 실제 목표 하나를 따라 가장 짧고 실용적인 경로로 검증 가능한 A2 기초를 다집니다.**

Language Learning Coach는 실제 과제, 신뢰할 수 있는 입력, 실용적인 표현, 능동적 인출, 상호작용, 집중 피드백, 지연 복습을 통해 학습하는 적응형 Codex Skill입니다.

프랑스어, 독일어, 이탈리아어, 스페인어, 포르투갈어, 한국어, 일본어, 아랍어, 영어처럼 자료가 충분한 현대 언어를 지원합니다. 일상, 여행, 업무, 학습, 시험, 읽기, 쓰기, 미디어, 계승어, 관심사 모두 가능한 경로입니다. 언어, 지역 변이, 문자 체계, 실제 목표, 시간, 수행에 따라 수업이 달라집니다.

> [!IMPORTANT]
> 내부 “A2형 선별 검사”는 CEFR의 공식 하위 등급이나 자격증이 아닙니다. A2는 익숙하고 일상적인 상황의 단순하고 직접적인 정보 교환을 다룹니다. 여행은 선택 경로이며, CEFR에서 여행 중 생길 법한 대부분의 상황에 대처하는 능력을 B1에 두므로 모든 여행이나 긴급 상황을 부담 없이 처리할 수 있다고 약속하지 않습니다. 유럽 평의회의 [CEFR 전체 등급표](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)와 [말하기 능력 기술표](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)를 참고하세요.

> [!NOTE]
> 이 프로젝트는 Kazuma가 공개적으로 공유한 학습 실천에서 영감을 받은 독립 오픈소스 프로젝트입니다. Kazuma가 공식적으로 만들거나 승인한 프로젝트가 아니며, 제휴나 추천 관계도 없습니다.

## 빠른 시작은 속성 학습을 뜻하지 않습니다

이 코치는 “배우고 싶다”는 생각에서 유용한 과제 하나를 끝내는 단계까지의 거리를 줄입니다. 목표 언어가 정해지면 말하기 수업 전에 무료 음성 환경을 확인하고, 여행을 전제로 하지 않는 중립적인 질문으로 목표를 확인한 뒤 첫 과제에 필요한 내용만 다룹니다.

신뢰할 수 있는 입력, 조건을 바꾼 연습, 시간을 두고 하는 재시험은 생략하지 않습니다. “빠르다”는 것은 현재 목표와 관계없는 단어 목록, 문법 순서, 일반 일정표, 자료를 줄인다는 뜻이며, 즉시 A2나 고정 기간을 약속하지 않습니다.

## 공통 A2 과제, 여행은 선택 경로

![교통, 숙박, 식사, 길 찾기, 쇼핑, 의사소통 복구로 이루어진 여섯 가지 핵심 여행 훈련 영역](assets/readme/travel-scenarios.svg)

내부 과제 지도는 개인 정보, 일상과 주변 환경, 필요와 거래, 시간·장소·방향, 선호와 사회적 교환, 의사소통 복구, 짧은 글과 쓰기의 일곱 공통 A2 영역을 사용합니다. 실제 목표에 맞춘 사용자 과제를 추가할 수 있지만 보수적인 내부 선별 검사에는 공통 영역만 계산합니다.

그림의 교통, 숙박, 식사, 길 찾기, 쇼핑, 의사소통 복구는 사용자가 여행을 선택했을 때의 선택 경로입니다. 심각한 의료·법률·출입국·안전 긴급 상황은 A2만으로 혼자 안전하게 처리할 수 있는 과제로 제시하지 않습니다.

학습 중인 표현마다 내가 실제로 쓸 버전, 바꿔 넣을 자리, 예상 후속 질문, 대화 복구 표현을 함께 저장합니다. 목표는 고정된 여행 회화집을 외우는 것이 아니라, 세부 조건 하나가 달라져도 과제를 끝내는 것입니다.

## 한 줄로 시작하기

```text
$language-learning-coach를 사용해 주세요. 한국어를 완전 처음부터 시작합니다.
무료 음성 환경을 먼저 준비한 뒤 유용한 첫 목표를 정해 주세요.
```

학습할 언어를 말하지 않았다면 첫 응답에는 다음 문장만 표시됩니다.

```text
어떤 언어를 배우고 싶나요?
```

언어가 정해지면 무료 음성 환경을 확인하고 “한국어로 가장 먼저 무엇을 하고 싶나요?”처럼 중립적으로 묻습니다. 한국에 왜 가는지를 전제로 묻지 않으며, 다음 수업을 바꾸는 질문만 한 번에 하나씩 합니다.

다음과 같이 시작할 수도 있습니다.

```text
$language-learning-coach를 사용해 주세요. 이집트 아랍어로 정중하게 부탁하는 법을
연습하고 싶습니다. 현지 구어와 현대 표준 아랍어를 구분해 주세요.
```

```text
$language-learning-coach를 사용해 주세요. 어제 하던 브라질 포르투갈어를 이어서
공부하고 싶습니다. 오늘은 5분밖에 없습니다.
```

## 가장 짧고 유용한 경로는 적응형입니다

![실제 과제에서 신뢰할 수 있는 입력, 인출, 상호작용, 피드백, 지연 전이로 이어지는 여덟 단계 순환](assets/readme/adaptive-loop.svg)

말하기 목표라면 보통 다음 순서로 수업이 진행됩니다.

1. 실제 과제 하나와 목표로 삼을 지역 변이를 정합니다.
2. 답을 보기 전에 출처 분류가 명시된 전체 음성 본보기를 듣습니다.
3. 의사소통 의도와 핵심 정보 하나를 파악합니다.
4. 바꿔 넣을 자리가 있는 전체 표현을 한 개에서 세 개 익힙니다.
5. 힌트가 하나씩 사라지는 동안 스스로 기억해 내고 바꾸어 말합니다.
6. 예상 후속 질문에 답하고, 필요하면 대화 복구 표현을 써서 짧은 상호작용을 마칩니다.
7. 과제 수행에 중요한 문제 한두 가지만 고친 뒤 곧바로 다시 해 봅니다.
8. 시간이 지난 뒤 장소, 시간, 사람, 물건, 조건 중 하나를 바꾸어 다시 시도합니다.

학습을 이어 갈 때마다 다음에 할 과제 하나와 구체적인 완료 조건을 먼저 분명히 제시합니다. 한 번의 실수는 관찰 사항으로만 남기며, 같은 패턴이 서로 다른 실제 수업일에 두 번 이상 나타날 때만 반복 오류 대기열에 올립니다. 같은 상황에서 현재 다루는 패턴을 실제로 구분해 써야 할 때, 코치는 최대 두 개까지 한 과제 안에서 교차해 연습하게 할 수 있습니다. 각 패턴을 따로 나누어 몰아서 반복하지 않습니다.

또한 지도 열기나 예약 확인처럼 이미 하던 행동에 연결한 약 30초짜리 마이크로 몰입 활동을 선택할 수 있습니다. 이 활동은 새로운 학습 내용을 자동으로 추가하지 않습니다. 완료했다는 자기 보고는 연습 이력으로만 기록되며, 능력별 증거 단계는 올라가지 않습니다.

읽기나 쓰기만을 목표로 할 때, 접근성, 새 문자, 성조·음높이·음장, 굴절, 높임말, 지역 변이, 양층언어에 따라 순서가 달라집니다. 일상, 여행, 업무, 학습, 시험, 읽기, 쓰기, 미디어, 계승어, 관심사는 동등한 경로입니다.

## 한 번의 미니 수업, 눈에 보이는 네 단계

![완전한 본보기 듣기, 과제 시도, 한 가지 집중 교정, 조건을 바꾼 재시도로 이어지는 네 장면](assets/readme/lesson-storyboard.svg)

1. **본보기:** 출처 분류가 명시된 표현 전체를 먼저 듣고, 필요할 때 글을 확인합니다.
2. **시도:** 학습자의 현재 실제 과제 안에서 표현을 사용합니다.
3. **집중 피드백:** 대화의 흐름을 살리면서 과제 수행에 가장 큰 영향을 주는 문제만 고칩니다.
4. **재시도:** 곧바로 과제를 한 번 더 마친 뒤 조건 하나를 바꾸어, 베끼기가 아니라 인출이 작동하게 합니다.

AI 역할극은 유용한 모의 훈련입니다. 하지만 원어민, 자연스러운 말하기 속도, 주변 소음, 낯선 억양, 예측할 수 없는 실제 반응에 대처했다는 증거는 아닙니다.

## A2를 방향으로 삼고, 능력별 증거를 기록합니다

![듣기, 말하기 산출, 읽기, 쓰기, 상호작용, 발음이 도움받은 연습에서 독립 수행, 조건 변경, 지연 후 유지로 이어지는 과정](assets/readme/evidence-ladder.svg)

듣기, 말하기 산출, 읽기, 쓰기, 상호작용, 발음을 따로 추적합니다. 표현을 들었다고 해서 곧바로 말할 수 있다고 보지 않습니다. 소리 내어 읽는 것은 상호작용의 증거가 아니며, 같은 수업에서 성공했다고 해서 기억이 유지되었다고 보지 않습니다.

증거 단계는 다음과 같습니다.

```text
도움받아 수행 → 독립 수행 → 조건을 바꾼 전이 → 지연 후 유지
```

작업 공간에는 과제, 힌트 수준, 증거 환경, **응답 매체**, 결과, 날짜, 다음 복습 시점을 기록합니다. 로마자 입력, 관찰할 수 없는 자기 보고, 답을 기다리는 과제를 실제 음성이나 목표 문자 쓰기로 잘못 저장하지 않습니다. A2 과제는 맞는 증거가 있을 때만 다음 단계로 올라갑니다.

과제 하나를 성공했다고 A2가 되는 것은 아닙니다. 내부 A2형 선별 검사는 일곱 공통 영역 중 다섯 개 이상의 서로 다른 핵심 표현에 대한 지연 또는 현실 확인, 의사소통 복구, 여섯 능력의 정확한 유지 증거, 실제 사람이나 현실 과제 확인을 요구합니다. 이후에도 “증거가 **검사한 과제에서의** A2형 수행과 일치한다”고만 말할 수 있으며 CEFR 공식 결과는 아닙니다.

## 음원 출처를 숨기지 않습니다

듣기·말하기 목표에서는 음성 환경 준비가 첫 작업입니다.

- **macOS:** 무료 기본 `say`와 `afconvert`를 사용하고, 목표 언어 음성이 없으면 시스템 설정에서 무료로 추가합니다.
- **Windows:** PowerShell `System.Speech`와 설치된 Windows 음성을 무료로 사용합니다. 목표 음성이 없으면 추가할 시스템 음성 기능을 설명하고 확인을 받은 뒤 설치합니다.
- **선택 온라인 대안:** 로컬 음성을 쓸 수 없을 때만 작업 공간의 격리 환경에 무료 `edge-tts`와 변환기를 설치해도 되는지 묻습니다. 인터넷이 필요하고 Windows 시스템 음성이 아니며 영구 제공을 보장하지 않습니다.

API 키, 신용카드, 유료 클라우드 TTS, 구독, 전역 Python 패키지 설치는 필요하지 않습니다. 첫 완전한 표현을 생성하고 기술 검증한 뒤 말하기 수업을 시작합니다. 읽기·쓰기 전용 또는 명시적 텍스트 전용 목표는 생략할 수 있습니다.

말하기 목표에서는 재생 가능한 음원이 있을 때 새 표현을 글로 확인하기 전에 먼저 듣습니다. 모든 본보기는 다음과 같이 분류합니다.

| 출처 분류 | 의미 | 근거로 사용할 수 있는 범위 |
|---|---|---|
| `native_official` | 목표 지역 변이의 원어민이 녹음한 공식 또는 기관 음원 | 출처가 실제로 다루는 자료에 대한 강한 본보기 |
| `native_traceable` | 화자와 출처를 추적할 수 있고, 지역 변이·맥락·사용역이 알맞은 원어민 음원 | 출처에 문서화된 범위 안에서의 본보기 |
| `tts` | 합성 음성 대체 수단임을 명확히 표시 | 초기 듣기와 예행연습. 원어민 본보기나 발음 능력의 증거는 아님 |
| `pending` | 신뢰할 수 있는 본보기가 아직 제공되지 않음 | 내용을 지어내지 않고 말하기 또는 발음 단계를 멈춤 |

TTS를 사용할 때는 표현·격식 확인, 목표 변이, 엔진 또는 음성, 실제로 전달한 파일／플레이어, 기술 검증을 각각 기록합니다. 파형을 재생할 수 있다는 사실만으로 표현의 자연스러움이 검증되지는 않습니다.

로컬 WAV 파일은 전달하기 전에 구조를 검증합니다. 기술적으로 유효하다는 사실이 출처의 신뢰성, 올바른 지역 변이, 실제 재생 여부, 발음 평가를 대신하지는 않습니다.

코치는 MP3나 녹음 업로드를 기본으로 요구하지 않고 발음 백분율도 제시하지 않습니다. 호스트가 음성 입력을 명확히 지원하고 학습자가 자발적으로 제공한 경우에만 실제로 들을 수 있는 일부 특징에 정성적 피드백을 줍니다.

## 설치

로컬 Skill을 지원하는 호스트와 TTS·음원·마이그레이션·작업 공간 도구를 실행할 Python 3가 필요합니다. 말하기 수업에는 macOS 또는 Windows 시스템 음성, 혹은 사용자가 허용한 무료 격리 온라인 대안이 필요합니다. 전달 검증기는 비압축 RIFF PCM WAV를 대상으로 합니다. Git 방식에는 Git도 필요합니다.

### 내장 Skill 설치 도구

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

또는 저장소를 다운로드한 뒤 그 내용을 다음 경로에 복사할 수 있습니다.

```text
~/.codex/skills/language-learning-coach
```

설치 후 Codex가 Skill을 인식하도록 새 Codex 작업을 시작하세요.

## 언어에 따라 경로가 달라지는 방식

| 언어 또는 목표의 특성 | 적응 방식 |
|---|---|
| 성조, 음높이 악센트, 음장 또는 강세 대립 | 산출 전에 지각 대조를 연습하고, 이어서 문장 단위로 훈련합니다. |
| 새롭거나 복잡한 문자 체계 | 소리와 문자를 함께 익히며, 전사 표기를 단계적으로 줄이는 계획을 세웁니다. |
| 굴절이 풍부하거나 교착성이 강한 구조 | 전체 표현과 함께 어간·접사를 일찍 분석하고 통제된 산출을 연습합니다. |
| 사용역, 높임말, 방언 연속체 또는 양층언어 현상 | 각 표현에 대화 상대와의 관계, 지역, 사용 매체 정보를 연결합니다. |
| 읽기, 쓰기, 업무, 시험, 미디어 또는 계승어 목표 | 실제 목표에 맞게 기능별 비중과 증거 과제를 바꿉니다. |

### 일반 표기를 적용할 수 있는 모든 언어의 소리–문자 기초 트랙

범위 안에 있고 적용 가능한 일반 표기가 있는 모든 언어에 누적형 소리–문자 기초 트랙을 둡니다. 듣기·말하기 목표이고 재생 가능한 음원이 있을 때는 유용한 완전한 표현을 먼저 소리로 듣고 정상 표기를 보여 준 뒤, 그 표현에서 작은 목표 하나만 꺼냅니다. 예를 들면 한글 자모나 음절 블록, 가나 대조나 문맥 속 한자 읽기, 아랍 문자의 연결형, 중국어 한자의 형태 구별, 또는 프랑스어·독일어처럼 익숙한 문자를 쓰는 언어의 철자–소리, 강세, 연음 규칙입니다. 연습은 즉시 완전한 표현으로 돌아가며, 문자표 전체를 외워야 의사소통을 시작할 수 있게 하지 않습니다.

전사가 필요하면 같은 수업에서 줄이거나 명시적으로 단계적 제거를 계획합니다. 도입한 단위나 규칙은 나중에 위치, 단어, 표지판, 인접 표현을 바꾼, 정답을 제시하지 않는 재시험으로 확인합니다. 이 트랙은 범위와 일정을 추적할 뿐 숙달 증거가 아닙니다. 읽기 전용, 표지판 읽기, 접근성 상황은 실제 매체에서 시작합니다. 듣기·말하기 목표에 재생 가능한 음원이 없으면 소리 과제를 멈추고 사용자가 동의한 뒤에만 문자 과제로 전환합니다. 어느 경우에도 듣기나 발음 증거를 꾸며 내지 않습니다.

위 예시는 고정된 지원 언어 목록이 아닙니다. 신뢰할 수 있는 음원, 사전, 문법 자료, 실제 용례 근거가 있다면 다른 현대 음성 언어나 문자 언어도 범위에 들어옵니다. 수어, 고전어, 인공어, 자료가 희소한 언어에는 이 Skill의 현재 범위를 넘어서는 전문 자료나 지도가 필요합니다.

## 로컬 학습 상태와 개인정보 보호

현재 작업 공간에 쓸 수 있다면 코치는 다음 파일을 관리할 수 있습니다.

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
├── function-map.md
└── progress.md       # A2 과제, 소리–문자 기초 트랙, 재시험, 수업 증거
```

읽기 쉬운 이 Markdown 파일에는 수업에 필요한 목표와 제약, 학습 습관을 시작하는 계기, 맥락이 있는 표현, 음원 출처 분류, 능력별 증거, 기초 의사소통 기능의 학습 범위, 소리–문자 기초 범위, 반복 오류 관찰, 선택적 마이크로 몰입, 예정된 복습을 저장합니다. 파일은 설치된 Skill 디렉터리가 아니라 사용자의 작업 공간에 남습니다. 내장 검증기는 구조와 내부 일관성만 확인하며, 기록된 학습 결과가 사실이라고 주장하지 않습니다.

이전 작업 공간에서는 추가형 마이그레이터가 예전 여행 지도 제목을 A2 과제 지도로 바꾸고 빠진 빈 소리–문자 표를 추가합니다. 기존 과제 행, 수업, 증거, 메모는 보존하며 예전 여행 영역을 다시 분류하지 않습니다.

이 저장소에는 원격 측정, 계정 연동, 백그라운드 서비스가 없습니다. 수업에 신뢰할 수 있는 언어 자료가 필요할 때 Codex와 사용자가 허용한 도구가 외부 출처에 접근할 수 있으며, 해당 제품의 개인정보 보호 규칙이 계속 적용됩니다.

## 학습법과 연구 근거

설계에는 Kazuma가 공개적으로 설명한 소리 우선 모방, 실용적인 표현, 능동 어휘, 실용 문법, 꾸준한 과제 중심 습관, 관심사 기반 입력이 반영되었습니다. 자세한 내용은 [학습법 요약과 일차 자료](references/kazuma-method.md)를 참고하세요.

이러한 실천을 하나의 과학적으로 검증된 체계로 취급하지는 않습니다. 이 Skill은 발음 지도, 정형화된 표현, 명시적 문법, 상호작용과 교정 피드백, 간격 학습과 인출, 의미 중심 입력, 자기조절에 관한 제2언어 습득 연구를 바탕으로 각 선택을 점검합니다. 자세한 내용은 [근거 매트릭스와 안전 원칙](references/evidence-and-guardrails.md)을 참고하세요.

이 README의 시각적 탐색 방식은 [byoungd/up](https://github.com/byoungd/up)의 언어 학습 부분을 참고했습니다. 반복 패턴과 교차 연습의 인터랙션 설계는 [m98/fluent](https://github.com/m98/fluent)에서, 기존 습관에 연결하는 선택적 연습은 [hamsamilton/lang-tutor](https://github.com/hamsamilton/lang-tutor)에서, 다음 행동 하나를 명확히 제시하는 방식은 [learn-anything-skill](https://github.com/vesperchinn/learn-anything-skill)에서 제품 설계 아이디어를 얻었습니다. 이 저장소들은 인터랙션 디자인을 위한 참고 자료일 뿐, 연구 근거가 아닙니다. 이 프로젝트의 구현, 문구, 시각 자료는 모두 독창적으로 만들었습니다.
