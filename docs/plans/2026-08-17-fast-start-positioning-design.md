# Fast-start positioning design

## Decision

Position Language Learning Coach around immediate use: once the target language and travel goal are known, the first lesson begins with one likely real-world task. Defer vocabulary lists, grammar sequences, generic calendars, and content unrelated to the learner's next trip.

“Fast start” means shortening the path from intention to useful performance. It does not mean promising a fixed time to A2, lowering evidence standards, or claiming stress-free travel.

## Scope

- Synchronize the positioning across the English, Simplified Chinese, Japanese, Korean, and Spanish READMEs.
- Add one concise “fast start, not a shortcut” explanation near the top of each README.
- Make the first-task behavior explicit in `SKILL.md`.
- Preserve the current travel domains, lesson loop, evidence model, validators, and CEFR boundary.

## Success criteria

- A new reader can tell within the opening screen that the coach starts with a real travel task rather than a long plan.
- All five README languages make the same promise and the same non-promise.
- The runtime instruction directs the coach to begin the first task immediately when enough information is known.
- Existing validation and tests remain green.
