# Language Learning Coach｜旅行向け A2 コーチ

**最初のレッスンから実際の旅行課題に取り組み、実際のパフォーマンスに合った最短の実用ルートで、検証可能な A2 の土台を築きます。**

![駅・ホテル・レストランをめぐる旅行と言語学習のイラスト](assets/readme/travel-hero.webp)

Language Learning Coach は、実際の課題、信頼できるインプット、役立つ表現、能動的な想起、やり取り、重点的なフィードバック、時間を置いた再テストを通じて、学習資料が十分にある現代言語を学ぶための適応型 Codex Skill です。

旅行で使う言語として、フランス語、ドイツ語、イタリア語、スペイン語、ポルトガル語、韓国語、日本語、アラビア語、英語などを主な対象としています。学ぶ言語、地域変種、文字体系、使える時間、そして実際にできたことに応じて、次のレッスンが変わります。

> [!IMPORTANT]
> 「旅行 A2」は本プロジェクト独自のトレーニングルートであり、CEFR の公式サブレベルでも、資格や認定でもありません。A2 が対象とするのは、身近で日常的な場面における単純で直接的な情報交換です。一方、CEFR では「旅行中に起こり得る大半の状況に対処できる」ことを B1 に位置づけています。そのため、本プロジェクトが目指すのは、**よくある予測可能な旅行場面で、より自信をもって対応できること**であり、あらゆる旅行や緊急事態に不安なく対処できるという約束ではありません。欧州評議会の [CEFR 全体尺度](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)と[話し言葉の評価尺度](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)も参照してください。

> [!NOTE]
> 本プロジェクトは、Kazuma 氏が公開している学習実践から着想を得た、独立したオープンソースプロジェクトです。Kazuma 氏の公式プロジェクトではなく、本人による許諾、提携、推奨を受けたものでもありません。

## すぐ始める。でも、速成を約束しない

このコーチは、「学びたい」と思ってから、切符の購入、チェックイン、注文、道案内、会話の立て直しを実際に行うまでの距離を縮めます。最初のレッスンでは、次の旅行で起こりそうな課題を一つ選び、それに必要な一〜三個のまとまった表現だけを学び、すぐに使います。

信頼できるインプット、条件を変えた練習、時間を置いた再テストは省きません。ここでいう「速さ」とは、次の旅行に関係のない語彙リスト、文法の学習順序、一般的な学習カレンダー、教材を減らすことです。すぐに A2 に到達すること、固定期間での修了、基準の引き下げを約束するものではありません。

## 連続記録ではなく、旅のために学ぶ

![交通、宿泊、食事、道案内、買い物、会話の立て直しという六つの中核旅行練習領域](assets/readme/travel-scenarios.svg)

標準の旅行ルートでは七つの成果を追跡します。図は日常的な六つの中核対話領域を示し、七つ目として安全範囲を限定した基礎的な助けの依頼を含みます。

- **交通：** 切符、乗り場、時刻、経路、変更について尋ねる。
- **宿泊：** チェックインし、予約内容を確認し、簡単な問題を説明する。
- **食事：** 注文し、希望を伝え、追加の質問を聞き取り、支払いを済ませる。
- **道案内：** 道を尋ね、目印を見つけ、理解が合っているか確認する。
- **買い物：** 値段、数量、サイズ、在庫、支払いに対応する。
- **会話の立て直し：** 繰り返す、ゆっくり話す、書く、指し示す、別の言い方にするよう相手に頼む。
- **基礎的な助け：** 薬局、遺失物、その他の非緊急の依頼に対応し、重大な緊急事態を A2 課題として扱わない。

学習中の各表現には、自分用の言い方、置き換え可能な部分、想定される追加質問、会話を立て直す表現を保存します。目標は決まり文句をそのまま暗記することではありません。一つの条件が変わっても、課題を完了できるようになることです。

重大な医療、法律、出入国、安全上の緊急事態について、A2 だけで安全に独力対応できるかのような扱いはしません。

## 一行で始める

```text
$language-learning-coach を使ってください。日本語をゼロから学び始めます。
毎日 15 分使え、日本旅行で基本的な会話に対応したいです。
```

まだ言語を指定していない場合、最初の応答は次の一文だけです。

```text
何語を学びたいですか？
```

その後も、コーチが一度に尋ねるのは一つだけで、次のレッスンが変わる場合に限ります。長いアンケートや一般的な学習カレンダーを受け取る代わりに、小さな実践課題をすぐに始めます。

次のように始めることもできます。

```text
$language-learning-coach を使ってください。エジプト・アラビア語で
丁寧に依頼する練習をしたいです。現地口語と現代標準アラビア語を区別してください。
```

```text
$language-learning-coach を使ってください。昨日のブラジル・ポルトガル語を
続けてください。今日は 5 分しかありません。
```

## 役に立つ最短ルートは、学習者に合わせて変わる

![実際の旅行課題から信頼できる入力、想起、やり取り、フィードバック、時間を置いた転移へ進む八段階のループ](assets/readme/adaptive-loop.svg)

旅行での聞き取りと会話を目標にする場合、典型的なレッスンは次の流れで進みます。

1. 実際の課題を一つ選び、対象とする地域変種を決める。
2. 答えを見る前に、音源区分が明示された完全なモデル音声を聞く。
3. 発話の意図と、重要な情報を一つ理解する。
4. 置き換え可能な部分を含む完全な表現を一つから三つ学ぶ。
5. ヒントを少しずつ減らしながら、表現を思い出して内容を変える。
6. 想定される追加質問と立て直し手段を含む、短いやり取りを完了する。
7. 課題の成否に関わる問題を一つか二つだけ直し、すぐにやり直す。
8. 時間を置き、場所、時刻、相手、物、条件のいずれかを変えて再挑戦する。

読むことや書くことだけが目標の場合、アクセシビリティ上の配慮が必要な場合、新しい文字体系、声調やピッチアクセント、複雑な語形変化、敬語、地域変種、ダイグロシアを扱う場合には、順序が変わります。旅行が主なルートですが、信頼できる資料があれば、仕事、試験、読解、作文、映像作品、継承語の目標にも対応します。

## 一回のマイクロレッスンで見える四つの動き

![完全なモデル音声を聞き、課題を試し、重点的な修正を一つ受け、条件を変えて再挑戦する四コマのレッスン](assets/readme/lesson-storyboard.svg)

1. **モデル：** 音源区分が明示された出典から、表現全体を聞く。必要に応じて、その後に文字を確認する。
2. **挑戦：** 切符売り場、ホテルのフロント、レストラン、店、道案内の課題でその表現を使う。
3. **重点フィードバック：** やり取りの流れを保ち、課題の達成に最も影響する点だけを直す。
4. **再挑戦：** すぐにもう一度完了し、次に条件を一つ変えて、書き写すのではなく想起して対応する。

AI とのロールプレイは有用な模擬練習です。ただし、母語話者、自然な速度、周囲の雑音、初めて聞くアクセント、予測できない現実の応答に対応できた証拠にはなりません。

## A2 を方向として、能力ごとに証拠を残す

![聞き取り、発話、読解、作文、やり取り、発音を、支援ありの練習、自力での完了、条件を変えた転移、時間を置いた保持へつなぐ図](assets/readme/evidence-ladder.svg)

聞き取り、発話、読解、作文、やり取り、発音は、それぞれ別に記録します。表現を聞き取れたからといって、話せることにはなりません。音読できても、やり取りができる証拠にはなりません。同じレッスン内で成功しても、保持できたとは限りません。

証拠の段階は次のとおりです。

```text
支援あり → 自力で完了 → 条件を変更 → 時間を置いて保持を確認
```

ワークスペースには、課題、ヒントの程度、証拠が得られた環境、**回答媒体**、結果、日付、次回の再テストを記録します。これにより、ローマ字入力、観察できない「言いました」という自己申告、まだ回答待ちの課題が、聞き取れる発話や目標言語の文字による作文として誤記録されることを防ぎます。旅行ミッションは、対応する証拠がある場合にだけ、同一セッションでの達成、条件変更、遅延保持、現実場面での確認へ進みます。

一つのミッションを達成しても A2 とは限りません。内部の A2 型スクリーニングが通るには、定義済みの七つの旅行領域のうち少なくとも五つで異なる中核表現を使った遅延確認または現実場面の確認を終え、会話の立て直しを含み、六つの能力すべてにミッション要件へ正確に結び付いた保持証拠があり、少なくとも一つのミッションが実在する相手または現実場面で通る必要があります。その後もコーチが述べられるのは「証拠が**テスト済み課題における** A2 型のパフォーマンスと一致する」という範囲で、未確認の点を明示します。これは CEFR 判定ではなく、正式な結果は適切な外部評価でのみ確認できます。上達の速さは、言語、出発点、練習時間、資料の質、そして条件変更と時間間隔を経てもパフォーマンスを維持できるかによって変わります。

## 音源の区分を隠さない

聞き取りや会話を目標にし、再生可能な音声がある場合、新しい表現は文字による答えを見る前に音声で聞きます。すべてのモデル音声を次のように分類します。

| 音源区分 | 意味 | 裏づけられること |
|---|---|---|
| `native_official` | 対象地域変種の母語話者による、公式または公的機関の録音 | 出典が実際に扱っている素材についての信頼性が高いモデル |
| `native_traceable` | 話者と出典を確認でき、地域変種、文脈、使用域が適切な母語話者の録音 | 出典に記録された範囲内でのモデル |
| `tts` | 合成音声であることを明示した代替音源 | 初期の聞き取りとリハーサル。母語話者モデルや発音習得の証拠にはならない |
| `pending` | 信頼できるモデル音声をまだ提示できていない | 内容を捏造せず、音声や発音の手順をいったん停止する |

TTS を使う場合、表現とレジスターの確認、対象変種、エンジンまたは音声、実際に提供したファイル／プレイヤー、技術検証を別々に記録します。波形が再生できても、表現の自然さまでは証明できません。

ローカルの WAV ファイルは、提示前に構造を検証します。技術的に有効であることは、出典の信頼性、地域変種の正しさ、実際に再生できること、発音を評価できることの代わりにはなりません。

## インストール

ローカル Skill を利用できる Codex と、付属の音声検証器およびワークスペース検証器を動かす Python 3 が必要です。音声検証器が受け付けるのは、従来形式の非圧縮 RIFF PCM WAV です。ほかの形式は先に変換してください。Git を使う方法では Git も必要です。

### 同梱の Skill Installer

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

または、リポジトリをダウンロードし、その内容を次の場所へコピーしてください。

```text
~/.codex/skills/language-learning-coach
```

インストール後は、新しい Codex タスクを開始して Skill を認識させてください。

## 言語に応じてルートを変える方法

| 言語または目標の特徴 | 適応方法 |
|---|---|
| 声調、ピッチアクセント、音長、強勢の対立 | 産出の前に知覚対比を行い、その後に文単位で練習する |
| 新しい、または複雑な文字体系 | 音声と文字を並行して進め、転写表記を段階的に減らす計画を立てる |
| 豊かな屈折や膠着構造 | 表現全体を保ちながら、早い段階で語幹と接辞を分析し、条件を制御した産出を行う |
| 使用域、敬語、方言連続体、ダイグロシア | 各表現に、対人関係、地域、媒体の情報を付ける |
| 読解、作文、仕事、試験、映像作品、継承語の目標 | 実際の目標に合わせて、技能の比重と証拠を得る課題を変える |

ここに挙げた例は、固定された対応言語一覧ではありません。ほかの現代の音声言語や書記言語も、信頼できる音声、辞書、文法資料、用法の根拠がそろっていれば対象になります。手話、古典語、人工言語、資料の乏しい言語には、本 Skill の現在の範囲を超えた専門資料や指導が必要です。

## ローカルの学習状態とプライバシー

現在のワークスペースに書き込める場合、コーチは次のファイルを管理できます。

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
├── function-map.md
└── progress.md       # 旅行ミッション、再テスト、レッスン証拠
```

これらの読みやすい Markdown ファイルには、コースに関係する目標、制約、習慣のきっかけ、文脈付きの表現、音源区分、能力別の証拠、基礎コミュニケーション機能の範囲、修正点、予定された再テストを保存します。ファイルは利用者のワークスペースに残り、インストール済みの Skill ディレクトリには書き込まれません。付属の検証器は構造と内部整合性だけを確認し、記録された学習成果が事実であるとは断定しません。

本リポジトリに、テレメトリー、アカウント連携、バックグラウンドサービスはありません。レッスンで信頼できる言語資料が必要な場合、Codex と利用者が許可したツールが外部の情報源へアクセスすることがあります。その場合も、それぞれの製品やツールのプライバシールールが適用されます。

## 方法と研究上の根拠

本設計は、音声を先に聞いて模倣すること、役立つ表現、能動語彙、実用文法、課題に基づく継続的な習慣、興味を軸にしたインプットについての Kazuma 氏の公開発言から着想を得ています。詳しくは[方法の要約と一次資料](references/kazuma-method.md)を参照してください。

これらの実践全体を、科学的に検証済みの一つの体系として扱うことはありません。Skill は、発音指導、定型表現、明示的文法、やり取りと訂正フィードバック、間隔学習と想起、意味重視のインプット、自己調整に関する第二言語習得研究と照らして、個々の選択を確認します。詳しくは[エビデンスマトリクスとガードレール](references/evidence-and-guardrails.md)を参照してください。

本 README の視覚的なナビゲーションは、[byoungd/up](https://github.com/byoungd/up) の言語学習セクションを参考にしています。このリポジトリの文章とアートワークはすべてオリジナルであり、上流リポジトリの写真やイラストは再利用していません。
