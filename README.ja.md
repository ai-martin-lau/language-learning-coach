# Language Learning Coach｜ゼロから始める A2 言語コーチ

**ゼロから始め、まず無料の音声環境を整え、一つの実際の目標から最短の実用ルートで検証可能な A2 の土台を築きます。**

Language Learning Coach は、実際の課題、信頼できるインプット、役立つ表現、能動的な想起、やり取り、重点的なフィードバック、時間を置いた再テストを通じて、学習資料が十分にある現代言語を学ぶための適応型 Codex Skill です。

フランス語、ドイツ語、イタリア語、スペイン語、ポルトガル語、韓国語、日本語、アラビア語、英語など、資料が十分な現代言語を対象とします。日常生活、旅行、仕事、学習、試験、読解、作文、映像、継承語、興味のいずれも選べるルートです。言語、地域変種、文字体系、実際の目標、使える時間、できたことに応じて次のレッスンが変わります。

> [!IMPORTANT]
> 内部の「A2 型スクリーニング」は、CEFR の公式サブレベルでも資格でもありません。A2 は身近で日常的な場面の単純で直接的な情報交換を扱います。旅行は選択肢の一つであり、CEFR が「旅行中に起こり得る大半の状況への対処」を B1 に置くため、あらゆる旅行や緊急事態に不安なく対応できるとは約束しません。欧州評議会の [CEFR 全体尺度](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)と[話し言葉の評価尺度](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)も参照してください。

> [!NOTE]
> 本プロジェクトは、Kazuma 氏が公開している学習実践から着想を得た、独立したオープンソースプロジェクトです。Kazuma 氏の公式プロジェクトではなく、本人による許諾、提携、推奨を受けたものでもありません。

## すぐ始める。でも、速成を約束しない

このコーチは、「学びたい」と思ってから一つの役立つ課題を完了するまでの距離を縮めます。対象言語が決まったら、話すレッスンの前に無料の音声環境を確認し、旅行を前提にせず目標を尋ね、最初の課題に必要な内容だけを扱います。

信頼できるインプット、条件を変えた練習、時間を置いた再テストは省きません。ここでいう「速さ」とは、現在の目標に関係のない語彙リスト、文法順序、一般的な学習カレンダー、教材を減らすことです。即時の A2、固定期間、基準の引き下げは約束しません。

## 共通 A2 課題。旅行は選択ルート

![交通、宿泊、食事、道案内、買い物、会話の立て直しという六つの中核旅行練習領域](assets/readme/travel-scenarios.svg)

内部の課題マップは、個人情報、日課と身近な環境、必要と取引、時刻・場所・方向、好みと社会的なやり取り、会話の立て直し、短文と作文という七つの共通 A2 領域を使います。実際の目標に応じて独自課題を追加できますが、保守的な内部スクリーニングで数えるのは共通領域だけです。

図の交通、宿泊、食事、道案内、買い物、会話の立て直しは、旅行を目標に選んだ場合の任意ルートです。重大な医療、法律、出入国、安全上の緊急事態を、A2 だけで安全に独力対応できる課題として扱いません。

学習中の各表現には、自分用の言い方、置き換え可能な部分、想定される追加質問、会話を立て直す表現を保存します。目標は決まり文句をそのまま暗記することではありません。一つの条件が変わっても、課題を完了できるようになることです。

## 一行で始める

```text
$language-learning-coach を使ってください。韓国語をゼロから始めます。
まず無料の音声環境を整え、その後で役立つ最初の目標を決めてください。
```

まだ言語を指定していない場合、最初の応答は次の一文だけです。

```text
何語を学びたいですか？
```

言語が決まったら無料の音声環境を確認し、「韓国語で最初に何ができるようになりたいですか？」のように中立に尋ねます。韓国へ行く目的を前提にせず、一度に質問するのは次のレッスンを変える一項目だけです。

次のように始めることもできます。

```text
$language-learning-coach を使ってください。エジプト・アラビア語で
丁寧に依頼する練習をしたいです。現地口語と現代標準アラビア語を区別してください。
```

```text
$language-learning-coach を使ってください。昨日のブラジル・ポルトガル語を
続けてください。今日は 5 分しかありません。
```

## 役に立つ最短ルートは、学習者に合わせて変わる

![実際の課題から信頼できる入力、想起、やり取り、フィードバック、時間を置いた転移へ進む八段階のループ](assets/readme/adaptive-loop.svg)

聞き取りと会話を目標にする場合、典型的なレッスンは次の流れで進みます。

1. 実際の課題を一つ選び、対象とする地域変種を決める。
2. 答えを見る前に、音源区分が明示された完全なモデル音声を聞く。
3. 発話の意図と、重要な情報を一つ理解する。
4. 置き換え可能な部分を含む完全な表現を一つから三つ学ぶ。
5. ヒントを少しずつ減らしながら、表現を思い出して内容を変える。
6. 想定される追加質問と立て直し手段を含む、短いやり取りを完了する。
7. 課題の成否に関わる問題を一つか二つだけ直し、すぐにやり直す。
8. 時間を置き、場所、時刻、相手、物、条件のいずれかを変えて再挑戦する。

学習を再開するたびに、次に取り組む課題を一つと、その具体的な完了条件を最初に明示します。一度の間違いは観察事項として記録するだけで、同じパターンが実際に行われたレッスンの異なる日付で二回以上確認された場合にのみ、反復エラーのキューに追加します。同じ場面で、現在取り組んでいるパターンを実際に使い分ける必要がある場合、コーチは最大二つまでを一つの課題に交互に組み込み、パターンごとに分けた反復練習にはしません。

また、地図を開く、予約を確認するといった、普段から行っていることに結び付けた約 30 秒のマイクロイマージョン活動を、希望に応じて取り入れられます。新しい学習内容が自動的に追加されることはありません。完了したという自己申告は練習履歴として記録されますが、能力を示す証拠の段階は上がりません。

読むことや書くことだけが目標の場合、アクセシビリティ上の配慮、新しい文字体系、声調やピッチアクセント、複雑な語形変化、敬語、地域変種、ダイグロシアに応じて順序が変わります。日常、旅行、仕事、学習、試験、読解、作文、映像、継承語、興味はいずれも同等のルートです。

## 一回のマイクロレッスンで見える四つの動き

![完全なモデル音声を聞き、課題を試し、重点的な修正を一つ受け、条件を変えて再挑戦する四コマのレッスン](assets/readme/lesson-storyboard.svg)

1. **モデル：** 音源区分が明示された出典から、表現全体を聞く。必要に応じて、その後に文字を確認する。
2. **挑戦：** 学習者が現在取り組む実際の課題でその表現を使う。
3. **重点フィードバック：** やり取りの流れを保ち、課題の達成に最も影響する点だけを直す。
4. **再挑戦：** すぐにもう一度完了し、次に条件を一つ変えて、書き写すのではなく想起して対応する。

AI とのロールプレイは有用な模擬練習です。ただし、母語話者、自然な速度、周囲の雑音、初めて聞くアクセント、予測できない現実の応答に対応できた証拠にはなりません。

## A2 を方向として、能力ごとに証拠を残す

![聞き取り、発話、読解、作文、やり取り、発音を、支援ありの練習、自力での完了、条件を変えた転移、時間を置いた保持へつなぐ図](assets/readme/evidence-ladder.svg)

聞き取り、発話、読解、作文、やり取り、発音は、それぞれ別に記録します。表現を聞き取れたからといって、話せることにはなりません。音読できても、やり取りができる証拠にはなりません。同じレッスン内で成功しても、保持できたとは限りません。

証拠の段階は次のとおりです。

```text
支援あり → 自力で完了 → 条件を変更 → 時間を置いて保持を確認
```

ワークスペースには、課題、ヒントの程度、証拠が得られた環境、**回答媒体**、結果、日付、次回の再テストを記録します。ローマ字入力、観察できない自己申告、回答待ちの課題を、聞き取れる発話や通常表記の作文として誤記録しません。A2 課題は対応する証拠がある場合だけ次の段階へ進みます。

一つの課題を達成しても A2 とは限りません。内部の A2 型スクリーニングには、七つの共通領域のうち少なくとも五つで異なる中核表現を使った遅延または現実確認、会話の立て直し、六能力の正確な保持証拠、実在する相手または現実課題での確認が必要です。その後も「証拠が**テスト済み課題における** A2 型のパフォーマンスと一致する」としか言えず、CEFR の正式結果ではありません。

## 音源の区分を隠さない

聞く・話す目標では、音声環境の準備が最初の操作です。

- **macOS：** 無料の標準 `say` と `afconvert` を使い、対象言語の音声がなければシステム設定から無料で追加します。
- **Windows：** PowerShell の `System.Speech` とインストール済み Windows 音声を無料で使います。対象音声がなければ、追加する音声機能を説明し、確認を得てからインストールします。
- **任意のオンライン代替：** ローカル音声が使えない場合だけ、作業領域の隔離環境へ無料の `edge-tts` と変換器を入れてよいか尋ねます。インターネットが必要で、Windows のシステム音声ではなく、永続的な提供も保証されません。

API キー、クレジットカード、有料クラウド TTS、購読、Python パッケージのグローバルインストールは不要です。最初の完全な表現を生成して技術検証してから音声レッスンへ進みます。読解・作文のみ、または明示的なテキストのみの目標では省略できます。

聞き取りや会話を目標にし、再生可能な音声がある場合、新しい表現は文字による答えを見る前に音声で聞きます。すべてのモデル音声を次のように分類します。

| 音源区分 | 意味 | 裏づけられること |
|---|---|---|
| `native_official` | 対象地域変種の母語話者による、公式または公的機関の録音 | 出典が実際に扱っている素材についての信頼性が高いモデル |
| `native_traceable` | 話者と出典を確認でき、地域変種、文脈、使用域が適切な母語話者の録音 | 出典に記録された範囲内でのモデル |
| `tts` | 合成音声であることを明示した代替音源 | 初期の聞き取りとリハーサル。母語話者モデルや発音習得の証拠にはならない |
| `pending` | 信頼できるモデル音声をまだ提示できていない | 内容を捏造せず、音声や発音の手順をいったん停止する |

TTS を使う場合、表現とレジスターの確認、対象変種、エンジンまたは音声、実際に提供したファイル／プレイヤー、技術検証を別々に記録します。波形が再生できても、表現の自然さまでは証明できません。

ローカルの WAV ファイルは、提示前に構造を検証します。技術的に有効であることは、出典の信頼性、地域変種の正しさ、実際に再生できること、発音を評価できることの代わりにはなりません。

コーチは MP3 や録音のアップロードを標準では求めず、発音の百分率も提示しません。ホストが音声入力に明確に対応し、学習者が自発的に音声を提供した場合だけ、実際に聞き取れた少数の特徴へ定性的なフィードバックを行います。

## インストール

ローカル Skill を利用できるホストと、TTS、音声、移行、ワークスペース用ツールを動かす Python 3 が必要です。音声レッスンには macOS または Windows のシステム音声、もしくは利用者が許可した無料の隔離オンライン代替が必要です。提示前検証は非圧縮 RIFF PCM WAV を対象とします。Git 方式では Git も必要です。

### 同梱の Skill Installer

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

または、リポジトリをダウンロードし、その内容を次の場所へコピーしてください。

```text
~/.codex/skills/language-learning-coach
```

インストール後は、新しい Codex タスクを開始して Skill を認識させてください。

## 言語に応じてルートを変える方法

| 言語または目標の特徴 | 適応方法 |
|---|---|
| 声調、ピッチアクセント、音長、強勢の対立 | 産出の前に知覚対比を行い、その後に文単位で練習する |
| 新しい、または複雑な文字体系 | 音声と文字を並行して進め、転写表記を段階的に減らす計画を立てる |
| 豊かな屈折や膠着構造 | 表現全体を保ちながら、早い段階で語幹と接辞を分析し、条件を制御した産出を行う |
| 使用域、敬語、方言連続体、ダイグロシア | 各表現に、対人関係、地域、媒体の情報を付ける |
| 読解、作文、仕事、試験、映像作品、継承語の目標 | 実際の目標に合わせて、技能の比重と証拠を得る課題を変える |

### 通常の表記が使えるすべての対象言語に音声と文字の基礎レーン

対象範囲にあり、適用できる通常の表記を持つすべての言語に、累積型の音声と文字の基礎レーンを設けます。聞く・話す目標で再生可能な音声がある場合は、まず役立つ表現全体を音で聞き、その後に通常の表記を示して、その表現から小さな目標を一つだけ取り出します。たとえば、ハングルの字母や音節ブロック、かなの対比や漢字の文脈上の読み、アラビア文字の連結形、中国語の字形の区別、またはフランス語・ドイツ語など慣れた文字を使う言語の綴りと音、強勢、連結発音の規則です。練習はすぐ表現全体に戻り、文字表を一通り覚えるまでコミュニケーションを止めることはありません。

転写表記が必要な場合は、同じレッスン内で減らすか、明示的な段階的削減を決めます。導入した単位や規則は、後日、位置・語・看板・近い表現のいずれかを変え、正解を見せない再テストで確認します。このレーンが記録するのは範囲と予定であり、習得の証拠ではありません。読解だけ、看板の識読、アクセシビリティ上の配慮は実際の媒体から始めます。聞く・話す目標で再生可能な音声がない場合は音声課題を止め、利用者の同意後にだけ文字課題へ切り替えます。どちらの場合も聞き取りや発音の証拠を捏造しません。

ここに挙げた例は、固定された対応言語一覧ではありません。ほかの現代の音声言語や書記言語も、信頼できる音声、辞書、文法資料、用法の根拠がそろっていれば対象になります。手話、古典語、人工言語、資料の乏しい言語には、本 Skill の現在の範囲を超えた専門資料や指導が必要です。

## ローカルの学習状態とプライバシー

現在のワークスペースに書き込める場合、コーチは次のファイルを管理できます。

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
├── function-map.md
└── progress.md       # A2 課題、音声—文字基礎レーン、再テスト、レッスン証拠
```

これらの読みやすい Markdown ファイルには、コースに関係する目標、制約、習慣のきっかけ、文脈付きの表現、音源区分、能力別の証拠、基礎コミュニケーション機能の範囲、音声—文字基礎の範囲、反復エラーの観察事項、任意のマイクロイマージョン、予定された再テストを保存します。ファイルは利用者のワークスペースに残り、インストール済みの Skill ディレクトリには書き込まれません。付属の検証器は構造と内部整合性だけを確認し、記録された学習成果が事実であるとは断定しません。

旧ワークスペースでは、付属の追加型移行ツールが旧旅行マップの見出しを A2 課題マップへ変更し、欠けている空の音声—文字表を挿入します。既存の課題行、レッスン、証拠、メモは保持し、旧旅行領域を再分類しません。

本リポジトリに、テレメトリー、アカウント連携、バックグラウンドサービスはありません。レッスンで信頼できる言語資料が必要な場合、Codex と利用者が許可したツールが外部の情報源へアクセスすることがあります。その場合も、それぞれの製品やツールのプライバシールールが適用されます。

## 方法と研究上の根拠

本設計は、音声を先に聞いて模倣すること、役立つ表現、能動語彙、実用文法、課題に基づく継続的な習慣、興味を軸にしたインプットについての Kazuma 氏の公開発言から着想を得ています。詳しくは[方法の要約と一次資料](references/kazuma-method.md)を参照してください。

これらの実践全体を、科学的に検証済みの一つの体系として扱うことはありません。Skill は、発音指導、定型表現、明示的文法、やり取りと訂正フィードバック、間隔学習と想起、意味重視のインプット、自己調整に関する第二言語習得研究と照らして、個々の選択を確認します。詳しくは[エビデンスマトリクスとガードレール](references/evidence-and-guardrails.md)を参照してください。

本 README の視覚的なナビゲーションは、[byoungd/up](https://github.com/byoungd/up) の言語学習セクションを参考にしています。反復パターンと交互練習のインタラクション設計は [m98/fluent](https://github.com/m98/fluent) から、既存の習慣に結び付ける任意の練習は [hamsamilton/lang-tutor](https://github.com/hamsamilton/lang-tutor) から、次の行動を一つだけ明示する設計は [learn-anything-skill](https://github.com/vesperchinn/learn-anything-skill) から、それぞれプロダクトデザイン上の着想を得ています。これらのリポジトリはインタラクションデザインの参考資料であり、研究上の根拠ではありません。本リポジトリの実装、文言、アートワークはすべてオリジナルです。
