# Language Learning Coach

言語学習を継続的な実践へと変える、適応型の Codex Skill です。信頼できる入力、実用的なチャンク、能動的な産出、実際のやり取り、重点的なフィードバック、遅延復習を一つの流れにまとめます。

対象言語、変種、表現媒体、目標、そして観察された学習者のパフォーマンスに応じてレッスンを変えます。信頼できる資料があれば、音声言語と書記言語、手話、古典語、構築言語、低資源言語に対応できます。

> [!IMPORTANT]
> 本プロジェクトは、Kazuma 氏が公開している学習実践から着想を得た独立したオープンソースプロジェクトです。Kazuma 氏の公式プロジェクトではなく、本人による許諾、提携、推奨を受けたものでもありません。

## この Skill の特徴

多くの AI 言語学習セッションは、その場限りの会話で終わります。Language Learning Coach は、継続的なコースとして設計されています。

- **抽象的な進捗より実際の課題を優先：** 目標を「食事を注文する」「追加の質問に答える」といった観察可能な行動に変えます。
- **実用的なチャンクから柔軟な使用へ：** 完成した表現を固定台本としてではなく、文脈、応答パターン、置換可能なスロットと一緒に学びます。
- **説明より先に練習：** 入力とやり取りから始め、その直前に使った表現から価値の高い文法パターンを一つ説明します。
- **連続記録ではなく証拠：** 習得は学習時間や復習したカード数ではなく、無提示の想起、転移、やり取り、時間を空けた後のパフォーマンスで判断します。
- **言語ごとの適応：** 声調、文字体系、豊かな形態論、使用域、手話空間、歴史的伝統に応じてレッスン設計を変えます。
- **継続的なローカル状態：** 学習プロフィール、表現バンク、パフォーマンスの証拠、次の復習キューを読みやすい Markdown で管理できます。

## 主な機能

- 初回オンボーディングは、正確に一つの質問 **`你要学习什么语言？`**（「何語を学びたいですか？」）から始まります。
- 適応型の日課、5 分間のメンテナンス、集中学習、実践後の振り返りモード。
- 信頼できる音声を使い、ツールの限界を明示するリスニング・発音練習。
- 手指要素と非手指要素を含む、動画優先の手話学習への適応。
- 実用文法、能動語彙、会話、読解、作文、試験対策。
- `new` から `retained` までの 6 段階の証拠状態を使った、遅延想起と転移の確認。
- デフォルトでは一つの言語を主学習にし、追加の言語をメンテナンスとしてローテーション。
- 孤立した単語の組み合わせではなく、「状況 → 表現」の想起を中心にした任意の Anki エクスポート。
- 低資源言語やコミュニティへの配慮が必要な言語に対する出典確認と、明示的な `needs_confirmation` 処理。

## 必要なものとインストール

ローカル Skill を利用できる Codex 環境が必要です。付属インストーラー方式には Python 3、Git でクローンする方式には Git が必要です。

### Codex 付属の Skill Installer でインストール

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ai-martin-lau/language-learning-coach \
  --path . \
  --name language-learning-coach
```

### Git でインストール

```bash
git clone https://github.com/ai-martin-lau/language-learning-coach.git \
  ~/.codex/skills/language-learning-coach
```

Git を使わない場合は、リポジトリをダウンロードし、その内容を次の場所へコピーしてください。

```text
~/.codex/skills/language-learning-coach
```

インストール後、新しい Codex タスクを開始すると Skill が認識されます。

## クイックスタート

Skill を直接呼び出します。

```text
$language-learning-coach を使って、言語学習を手伝ってください。
```

まだ言語を指定していない場合、最初の応答は次の一文だけです。

```text
你要学习什么语言？
```

具体的な目標から始めることもできます。

```text
$language-learning-coach を使ってください。日本語をゼロから始めます。
毎日 15 分使えます。日本旅行で基本的な会話ができるようになりたいです。
```

```text
$language-learning-coach を使ってください。アメリカ手話コミュニティのイベントで
自己紹介できるようにしてください。短い動画を見たり録画したりできます。
```

```text
$language-learning-coach を使ってください。昨日のブラジルポルトガル語の
レッスンを続けてください。今日は 5 分しかありません。
```

コーチは次のレッスンを変える情報だけを質問し、長いアンケートや一般的な学習計画を返す代わりに、小さな実践課題をすぐに始めます。

## レッスンの適応方法

| 言語または目標の特徴 | 適応方法 |
|---|---|
| 声調、ピッチアクセント、音長、または強勢対立 | 産出前に知覚対比を行い、その後に文単位で練習 |
| 新しい、または複雑な文字体系 | 音声と文字を並行して進め、転写表記を段階的に減らす計画を作成 |
| 豊かな屈折または膠着 | 完成したチャンクに加え、語幹・接辞の早期分析と制御された産出を実施 |
| 使用域、敬語、方言連続体、またはダイグロシア | 各表現に対人関係、地域、媒体を付与 |
| 手話 | 発音練習を、信頼できる動画、手話空間、動き、方向、非手指標識に置き換える |
| 古典語、歴史語、または典礼言語 | テキスト伝統、形態論、コーパスの証拠、明示した発音伝統を優先 |
| 低資源言語、またはコミュニティへの配慮が必要な言語 | コミュニティや機関の資料を優先し、不確かな内容を作り出さない |
| 試験、読解、作文、仕事、旅行、または継承語という目標 | 実際の目標に合わせて技能の比重と評価課題を変更 |

固定された「対応言語」リストはありません。対応の程度は、求める表現媒体と利用可能な資料の質に左右され、確認できない内容がある場合はコーチが明示します。

## 学習状態とプライバシー

現在のワークスペースに書き込める場合、コーチは次のファイルを管理できます。

```text
language-learning/<language-slug>/
├── profile.md
├── phrase-bank.md
└── progress.md
```

これらのファイルには、目標と制約、文脈と出典を伴う表現、観察されたパフォーマンス、修正点、予定された復習など、コースに必要な情報だけを保存します。ファイルは利用者のワークスペースに残り、インストール済みの Skill ディレクトリには書き込まれません。

本リポジトリにテレメトリー、アカウント連携、バックグラウンドサービスはありません。レッスンで最新または信頼できる言語資料が必要な場合、Codex と利用者が許可したツールは外部の情報源へアクセスすることがあります。その場合も、それぞれのプライバシールールが適用されます。

## 方法と根拠

レッスンは次のサイクルで進みます。

```text
信頼できる入力 → 文脈のあるチャンク → 知覚と模倣 → 産出
→ やり取り → 重点的なフィードバック → 遅延想起
```

この設計は、音を優先した模倣、実用的な表現、能動語彙、実用文法、課題に基づく継続的な習慣、興味を軸にした没入についての Kazuma 氏の公開発言から着想を得ています。詳しくは[方法の要約と一次資料](references/kazuma-method.md)を参照してください。

これらの実践全体を、科学的に検証済みの体系として扱うことはありません。Skill は、発音指導、定型表現、明示的文法、やり取りと訂正フィードバック、間隔学習と想起、意味重視の入力、自己調整に関する第二言語習得研究と照らして個々の選択を確認します。詳しくは[エビデンスマトリクスとガードレール](references/evidence-and-guardrails.md)を参照してください。

コーチは、固定日数での流暢さ、母語話者と同じ発音、すべての言語で同一の資料品質を約束しません。また、連続記録、学習時間、当日の成功、Anki の正答率だけで習得を判断しません。
