# Kazuma 方法：来源、可执行原则与边界

## 何时读取

在设计起步课程、选择语块、解释本 skill 与 Kazuma 的关系、比较学习工具或处理多语言维护时读取。不要把本文件当成 Kazuma 官方课程授权。

## 核心模型

将 Kazuma 反复描述的方法概括为：

1. 以交流任务为目标，而不是先积累脱离使用场景的知识。
2. 先听母语者使用的完整短语，并以整块声音模仿。
3. 同时建立可立即使用的语块库存、听觉印象和发音动作。
4. 从已积累的例子观察规律，再用实用语法核对和扩展。
5. 继续把听说训练与读写、语法和词汇并行推进。
6. 通过真实互动、独白、日记和兴趣内容把知识变成主动能力。
7. 用固定触发点和固定任务量形成习惯，不以单纯学习时长代表产出。

这是一套来自个人实践的学习系统，不是作为整体经过对照实验验证的独家教学法。

## 本人明确主张与教练转译

| 本人公开主张 | 转化为教练行为 | 不要误写成 |
|---|---|---|
| 先模仿母语声音和实用短语 | 先给可靠示范，再让用户听辨、模仿和使用 | 语法不重要或永远不学语法 |
| 以短语而非孤立单词起步 | 保存完整场景、搭配、用户回答和可替换槽位 | 背固定台词就能流利 |
| 先积累例子，再观察并核对语法 | 从刚用过的句子引出简短规则并马上迁移 | 必须学完固定句数才能碰语法 |
| 口语像运动，需要实际开口 | 尽早进行低风险、目标明确的微型互动 | 只要多说就会自动正确 |
| 主动词汇比只认得的词更重要 | 要求无提示提取、自己造句和真实使用 | 被动词汇无价值 |
| 固定时间、固定完成量 | 设计每日可完成的一课和最低维护任务 | 每天必须学习固定小时数 |
| 把语言放进兴趣和生活 | 用音乐、影视、食物、人物或社群选择内容 | 娱乐性输入无需注意或练习 |
| 一次集中推进一门语言 | 默认一门主攻语言，其他语言轮换维护 | 人绝对不能同时学两门语言 |

## Kazuma 风格起步功能

以下是其公开“30 个起步短语”的**沟通功能转述**。把它们作为可调整的功能图，而不是固定课序：按用户近期真实任务确定优先级，可重排、暂缓或标为不相关；清单外的真实任务保存在语块库中，不虚构为第 31 个 Kazuma 功能。让每个在学功能关联具体语块和下一次表现任务；目标或表现变化后重新排序。不要把整份清单机械交给所有人，也不要把完成清单称为流利。

### 建立联系

1. 询问姓名。
2. 询问来自哪里。
3. 询问居住地。
4. 询问近况。
5. 把同一问题回问对方。
6. 初次见面致意。
7. 询问正在做什么。

### 谈论语言与个人经历

8. 询问是否会说某种语言。
9. 询问学习语言的原因。
10. 给出自己的原因。
11. 询问学习了多久。
12. 询问兴趣爱好。
13. 询问是否有某种经历。
14. 请求做某件事的许可。
15. 询问某件事发生的时间。
16. 询问是否喜欢某物或某事。
17. 询问一个表达的意思。
18. 询问能力或可能性。
19. 询问是否拥有某物。
20. 请求对方重复。

### 完成旅行与日常任务

21. 询问价格。
22. 表达想去某地。
23. 询问路线。
24. 询问选择中的哪一个。
25. 询问某人是谁。
26. 询问时间。
27. 请求饮食推荐。
28. 做出购买或点单选择。
29. 请求结账。
30. 提出礼貌请求。

为每个功能同时准备：

- 用户真正会说的回答或请求。
- 一个对方可能提出的追问。
- 一个可替换槽位。
- 一个沟通失败时的修复表达。

分别记录该功能在听懂、主动口语、阅读、写作和互动等适用维度中的证据，不因一个语块能背出或一个维度成功就把整个功能标为掌握。把“能流畅说出”理解为起步支架的一个表现证据，仍需用新情境迁移和延迟复测确认。

## 声音训练

先为每条有声示范记录来源等级、目标变体、交付方式和该来源实际支持的判断：

1. `native_official`：由目标变体母语者录制的官方或机构音频。
2. `native_traceable`：说话者和出处可追溯、情境与语域适合的目标变体母语音频。
3. `tts`：只在前两类暂不可得时使用，并在播放器旁明确标为合成语音。

TTS 可以支持初步听辨和跟读排练，但不能单独证明已经接受母语示范、表达符合母语者实际用法或发音已经掌握；相应项目保留“待母语音频核实”。文件技术验证、实际可播放性和语言来源可靠性是三个独立检查。

Kazuma 的公开步骤可转译为：

1. 仔细听一条最高可用来源等级的完整示范；若只能用 TTS，把训练结论限制在初步感知与排练。
2. 先模仿整体节奏和声音连接，再查看必要文字说明。
3. 观察口形、舌位、喉部动作、声调或音高变化；只关注该语言真正有区别作用的特征。
4. 录下自己的版本。
5. 与原音对比并只选一个高价值差异重做。
6. 把表达放进微型对话。

避免用母语谐音替代真实声音。允许音标或转写作为临时支架，但制定淡出计划。把“自己能发出的声音较容易辨认”保留为经验性假设，不宣传为无条件定律。

## 语法、读写与 overlapping

不要把阶段理解为互斥模块。进入语法和读写后继续听和模仿。

优先选择同时包含以下元素的材料：

- 对话或短故事。
- 原文与可靠音频。
- 能从语境说明的实用语法。
- 可用于同步朗读并把声音与文字对应的内容。

允许先让学习者根据熟悉语块猜一个模式，再给规则“对答案”。如果错误规律会快速固化、目标是考试，或某条规则能立即减少大量困惑，则提前做简短显性说明。

本 Skill 把上述 overlapping 原则具体化为“声音—文字基础支线”：从已经听懂或理解的实用语块中抽取一个小型字形、拼写—声音或连接规律，立即放回语块并安排延迟复测。这是为跨语言稳定执行而加入的独立教学设计，不是 Kazuma 公开规定的固定字符数量、字母课序或原版课程步骤。

## 主动词汇与复习

将词放回完整例句、真实场景和声音中。要求用户：

- 先理解语境中的意义。
- 无提示提取完整表达。
- 用该词生成自己的句子。
- 在对话或写作中再次调用。
- 经过间隔后重新完成任务。

Kazuma 公开提到 Anki，并重视根据难度安排复习。将 Anki 视为可选容器，不把卡片算法或正确率当成交际能力。

## 教材功能，不绑定品牌

Kazuma 公开介绍过 Pimsleur、Assimil、Kendra's Language School、Easy Languages、Anki 及其他资源。抽取以下功能来选材料：

- 音频优先、要求学习者主动回答。
- 高频且可以实际使用的表达。
- 次日或后续课程包含提取式复习。
- 短故事、真实会话和语境语法。
- 同一材料尽量支持听、说、读等多项能力。
- 难度让用户能理解主体内容，同时含少量新信息。

不要宣称某个付费产品适合所有语言、所有母语或所有目标。若推荐具体资源，重新核实其当前语言覆盖、教学媒介、价格和可用性。

## 习惯、独立产出与真实使用

采用以下可执行设计：

- 不让建档阻塞第一课；从第一个微型任务结束时开始，逐步记录或明确暂缓稳定触发点、约 5 分钟最低任务、可立即打开的材料和低动力备用动作，一次只补问一个缺口。
- 用“完成一课／完成一次对话任务”代替只计时。
- 把课程绑定在稳定生活触发点；动力不足时执行最低任务，而不是完全中断。
- 将独白、情境预演、两三句日记和兴趣输入作为循环出现的产出选项，并让它们复用当前语块；按学习目标选择，不要求每天四项全做。
- 把 AI 角色扮演记为模拟练习（`simulation`），不能记作与真人互动的证据。在用户同意且实际可行时安排可选的真人或现实场景检查点，并只记录实际发生的任务、结果和证据来源。
- 主攻语言使用完整闭环；维护语言用轮换输入、短复测和偶尔互动减缓遗忘。
- 允许同一材料多次回访，不把一次忘记判定为失败。

## 解释边界

- 把“掌握多种语言”视为作者和出版方的自我描述，不转写成独立标准化测评结果。
- 不保证复制个人经历即可在相同时间达到相同水平。
- 不把约 30 个起步功能或约 3000 个高频词变成通用阶段门槛。
- 不把某个理解百分比宣传为精确科学阈值；用任务表现动态调整难度。
- 不称本 skill 为官方、授权、合作或代言产品。
