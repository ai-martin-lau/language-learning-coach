# 跨语言适配

## 何时读取

首次教授一种新的现代有声或书面语言及其变体时读取；当现有流程明显带有英语假设时重新读取。

## 原则

不要用固定语言清单定义能力。先描述目标语言实际具有的特征，再选择训练动作。语言类型标签只是线索，不能替代对具体语言、变体和用户目标的核实。

## 建立语言特征档案

只把会改变教学的项目写入 `profile.md`：

### 身份与使用范围

- 精确语言名称及用户采用的自称。
- 地区、社群、时代和变体。
- 正式、非正式、礼仪、网络、专业或家庭语域。
- 用户要接触的人、内容和场景。
- 是否存在多个标准、方言连续体或明显双言分工。

### 表达媒介

- 口语／有声语言。
- 现代书面语言。
- 混合媒介、辅助沟通或无障碍需求。

判定为“有声语言＋听说目标＋可播放声音”时，执行互动协议中的有声输入门槛；文字、转写、音标和口型说明都不能替代声音。该门槛不适用于明确的纯阅读或写作目标。因无障碍需求改用其他媒介时，明确课程媒介已经改变，不声称完成听力或发音教学。

为每条有声示范使用统一来源等级：`native_official` 表示目标变体母语者的官方或机构录音；`native_traceable` 表示说话者与出处可追溯，且情境、语域适合；`tts` 只表示明确标注的合成语音后备。官方提供的合成语音仍属于 `tts`；母语者示范若变体或语域不匹配，也只能支持其实际覆盖的部分。只有 TTS 时可以做初步感知和排练，但保留母语示范与发音核实待办，不把技术验证当作语言可靠性。

### 感知与产出特征

- 音位对立、声调、音高重音、重音、音长、节奏、连读和弱化。
- 哪些差异会改变意义，哪些只是可接受变体。

### 文字与转写

- 当前使用的书写系统和正字法标准。
- 文字与声音的对应透明度。
- 分词、附标、连写、大小写或方向等阅读要求。
- 音标、罗马化、转写、注音或 gloss 是否只是临时支架。
- 罗马字或转写回答记为 `romanization`：它可以显示形式提取，但不能作为正常目标文字写作或可听口语证据。
- 在档案中把正常目标文字脚本记录为 `latin`、`hangul`、`japanese`、`arabic`、`cyrillic`、`greek`、`hebrew`、`devanagari`、`thai`、`han`、`other` 或 `not_applicable`；`target_text` 证据必须实际包含对应脚本文字，不能只改标签。

### 词汇与语法

- 基本语序和信息结构。
- 屈折、黏着、分析结构、复合或其他构词方式。
- 性、数、格、类别、敬语、证据性、体貌或其他高价值范畴。
- 主语省略、话题突出、代词系统或空间语法等影响早期表达的特点。

### 资料条件

- 权威或社群认可的词典、语法、语料和正字法说明。
- 与目标变体相符的母语音频及现代文本。
- 是否只能获得有限文本或非母语教学资料；资料不足时不要声称支持完整课程。
- 社群对外部教学、记录或分享是否存在伦理和许可要求。

不要把这份清单逐条问给用户。先利用用户已给信息和可靠资料，只在一个缺口会改变下一课时询问。

## 按特征改变课程

### 声调、音高重音、音长或重音对立

- 先训练最小或近最小听辨，再要求产出。
- 用多个词和多个说话者检查，不只练一个固定短语。
- 结合整句中的实际变调、重音移动或节奏，不只练孤立音节。
- 有可靠工具时使用音高轨迹或波形作为辅助；不要把图形匹配等同于自然表达。
- 不允许只看拼音、罗马字或重音符号而跳过声音。

### 所有语言的声音—文字基础支线

每种受支持且具有适用正常书写形式的语言都把可靠输入与目标文字连接起来，但不要把“通用流程”误写成所有语言使用同一种字母课。根据用户的既有文字能力与目标选择文字单位：字母、音节块、假名、整词汉字及其语境读音、字形构件、拼写—声音组合、重音、静音、分词或连读提示都可以成为当前单位。没有适用书写形式或档案明确为 `not_applicable` 时不强建支线。

对有声语言的听说目标，每次通常只加入一个文字微目标，并按以下顺序执行：

1. 先交付一个近期可用的完整语块声音，让学习者判断功能或完成意义任务，不显示目标文字或转写。
2. 学习者作答后再显示正常目标文字；只有确有需要时才附临时转写。
3. 从这个已理解语块抽取一至五个小型学习单位，或一个紧凑的拼写／重音／连接规律。
4. 立即回到完整语块，做一次辨认位置、声音—字形匹配、分段、拼合、重建或替换；孤立对比只能是短暂支架，不能代替语块。
5. 当课尽量把转写从 `full` 降为 `partial` 或 `none`，然后再次用正常目标文字完成一个动作。
6. 在后续真实课次用新的位置、词、标识或邻近语块做无答案复测；未产生直接任务证据时只记录已介绍和待复测，不写掌握。

旅行听说路线通常每课最多引入一个新的基础单位组，避免它挤掉真实沟通任务；“一个单位组”与“每轮只要求一个学习者动作”是两条独立限制。阅读或写作目标可根据表现提高基础支线比例。纯阅读、纯写作或无障碍目标按实际媒介直接进入；听说目标因音频不可用而转为非声音任务时仍须遵守用户同意门槛。不得由文字任务生成听力或发音证据。

按文字系统进一步适配：

- 韩语在已知语块中训练少量 jamo、音节块与实际组合，不先倾倒完整辅音／元音表。
- 日语从已知语块抽取少量 mora／假名；汉字以整词形义和该语境读音连接，不当成可逐字拼读字母。
- 阿拉伯语先固定地区与语域，再在真实词形中训练从右向左、连接形及相关声音；不从无短元音正文独立推断完整发音。
- 中文先连接已知口语词块与正常汉字，再注意少量整词字形或构件；拼音只作临时支架，不算目标文字。
- 使用学习者已熟悉字母表的法语、德语、西班牙语等语言，训练该语言真正高价值的拼写—声音组合、重音、静音或连读，不重新教授 ABC。

在 `progress.md` 的声音—文字基础支线中累计单位或规律、实质语块锚点、当前与复测转写支架、隐藏答案声明、真实变化条件和到期日。`symbol_sound`、`spelling_sound`、`stress` 与 `connected_speech` 必须锚定已有完整可靠音源；只辨认整词字形、意义或构件时使用 `form_component`，不得暗示已经学到读音。非无障碍转写在复测时必须减少，变化条件不能只重复原题。该表只负责覆盖与调度，不能推进任何语块、旅行任务或 A2 筛查状态；听力、主动口语产出、阅读、写作、互动和发音结果仍分别写入 `phrase-bank.md`。只有任务明确测试目标正字法时，目标文字输入才升级写作；在文字角色扮演中打出口语台词只支持该文字模拟，不自动证明写作或口语。避免把相似字形、拼写规则或字符数量当作孤立记忆竞赛。

### 高度屈折、黏着或复杂构词

- 保留完整语块，同时标出词干、词缀或变化位置。
- 先选择能覆盖用户高频意图的少量范式。
- 让用户替换一个语义特征并重建形式，例如人物、数、格、时体或礼貌程度。
- 对不规则高频形式单独作为语块学习，不要求先背完整范式表。
- 使用新词测试能否生成，避免只认得分析结果。

### 语序、话题或省略差异明显

- 用信息结构和真实语境解释顺序，不只给母语逐词对照。
- 对比“谁已知、谁是新信息、谁被省略”，再让用户改换焦点。
- 避免把自然省略机械补成完整书面句，或把书面顺序强加到口语。

### 敬语、语域、双言或方言连续体

- 在每条材料中记录说话者关系、场合、地区和媒介。
- 先教一个与用户真实场景一致的稳定语域，再展示对比。
- 不把正式书面标准称为唯一“正确语言”，也不把社群变体称为错误。
- 让用户练习识别语域，即使暂时只要求产出其中一种。

## 适配功能图与证据

约 30 个 Kazuma 风格起步功能只用于目标相关的沟通支架。按用户场景重排、暂缓或标为不相关；清单外的真实任务直接进入 `phrase-bank.md` 并将起步功能编号写为 `not_applicable`，不要为了覆盖数字而教授不适用内容。为每个在学功能保存符合该语言和媒介的学习者版本、可替换槽位、可能追问与修复方式；对纯阅读或写作目标，把任务改写成相应媒介中的真实行为，而不是强行套入口语问答。

只跟踪任务实际测试的维度：听力、主动口语产出、阅读、写作、互动和发音。将其他维度标为不适用；一种技能中的成功不能自动升级另一种。独白、情境预演和短日记也按目标改写，例如写作目标使用延迟重写。

## 按学习目标改变优先级

| 目标 | 优先顺序 |
|---|---|
| 日常交流／旅行 | 沟通修复、声音感知、场景语块、互动、实用语法 |
| 工作／专业 | 场景任务、语域、行业语料、互动和写作准确性 |
| 考试 | 考纲与题型、诊断、目标语法／词汇，同时保留与考试相关的实际技能 |
| 阅读原著 | 文字、形态、句法、高频词、分级到真实文本；口语按需 |
| 写作 | 范文分析、语域、生成、反馈、修订和延迟重写 |
| 影视／播客 | 听辨、连读／变体、可理解输入、片段复述和互动表达 |
| 传承语学习者 | 先诊断口语、听力、识字和语域的不对称，不按零基础处理 |
| 发音专项 | 感知、动作、反馈和新词迁移，不用语法进度代表成果 |

默认实际沟通，但用户目标优先。不要因为方法来源偏口语，就强行把阅读、写作或考试目标改造成同一种课程。

## 多语言组合

默认设一门 `active` 语言，其余为 `maintenance`。安排维护时：

- 将相似语言放在不同时间或不同场景，减少早期混淆。
- 为每种语言使用不同人物、内容主题、颜色或媒介作为检索线索。
- 发现干扰时记录具体形式，不泛称“语言太像所以不能一起学”。
- 根据用户真实时间减少新内容，而不是把所有语言都安排成完整日课。

如果用户明确要求多门同时主攻，说明总练习量和干扰风险后执行，不把默认建议当禁令。

## 资料核实梯度

按内容风险选择证据：

1. 社群／官方规范、权威词典、原始语料或教学机构。
2. 目标变体母语者的可定位原生内容。
3. 正式出版教材或同行评审描述。
4. 多个相互独立、可追溯的可靠例子。
5. 模型推断只能用于提出待核实候选，不能把未核实内容当成确定答案。

记录来源支持的是翻译、发音、语域、频率还是文化用法。一个来源支持其中一项，不自动支持全部。
