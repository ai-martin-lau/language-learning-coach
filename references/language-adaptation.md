# 跨语言适配

## 何时读取

首次教授一种新语言、变体、手语、古典语言或低资源语言时读取；当现有流程明显带有英语假设时重新读取。

## 原则

不要用固定语言清单定义能力。先描述目标语言实际具有的特征，再选择训练动作。语言类型标签只是线索，不能替代对具体语言、变体和用户目标的核实。

## 建立语言特征档案

只把会改变教学的项目写入 `profile.md`：

### 身份与使用范围

- 精确语言名称及用户采用的自称。
- 地区、社群、时代和变体。
- 正式、非正式、礼仪、网络、专业或家庭语域。
- 用户要接触的人、内容和场景。
- 是否存在多个标准、方言连续体或明显双言分工。

### 表达媒介

- 口语／有声语言。
- 手语／视觉动作语言。
- 主要书面、古典、礼仪或重建传统。
- 混合媒介、辅助沟通或无障碍需求。

### 感知与产出特征

- 音位对立、声调、音高重音、重音、音长、节奏、连读和弱化。
- 手形、位置、方向、移动、空间指代、面部和身体等非手控成分。
- 哪些差异会改变意义，哪些只是可接受变体。

### 文字与转写

- 当前使用的书写系统和正字法标准。
- 文字与声音的对应透明度。
- 分词、附标、连写、大小写或方向等阅读要求。
- 音标、罗马化、转写、注音或 gloss 是否只是临时支架。

### 词汇与语法

- 基本语序和信息结构。
- 屈折、黏着、分析结构、复合或其他构词方式。
- 性、数、格、类别、敬语、证据性、体貌或其他高价值范畴。
- 主语省略、话题突出、代词系统或空间语法等影响早期表达的特点。

### 资料条件

- 权威或社群认可的词典、语法、语料和正字法说明。
- 与目标变体相符的母语音频或视频。
- 是否只能获得历史录音、有限文本或非母语教学资料。
- 社群对外部教学、记录或分享是否存在伦理和许可要求。

不要把这份清单逐条问给用户。先利用用户已给信息和可靠资料，只在一个缺口会改变下一课时询问。

## 按特征改变课程

### 声调、音高重音、音长或重音对立

- 先训练最小或近最小听辨，再要求产出。
- 用多个词和多个说话者检查，不只练一个固定短语。
- 结合整句中的实际变调、重音移动或节奏，不只练孤立音节。
- 有可靠工具时使用音高轨迹或波形作为辅助；不要把图形匹配等同于自然表达。
- 不允许只看拼音、罗马字或重音符号而跳过声音。

### 新文字或复杂文字系统

- 根据目标决定声音与文字的起步比例，不假设必须先学完字母表或完全延后文字。
- 对主要交流目标，先用少量高价值文字支持已学声音和语块。
- 对阅读目标，提高文字辨认、构形、分词和书写练习比例。
- 将转写当作可逐步淡出的支架；为屏幕阅读器、输入法或其他无障碍需求保留必要支架。
- 避免把相似字形、拼写规则或字符数量当作孤立记忆竞赛。

### 高度屈折、黏着或复杂构词

- 保留完整语块，同时标出词干、词缀或变化位置。
- 先选择能覆盖用户高频意图的少量范式。
- 让用户替换一个语义特征并重建形式，例如人物、数、格、时体或礼貌程度。
- 对不规则高频形式单独作为语块学习，不要求先背完整范式表。
- 使用新词测试能否生成，避免只认得分析结果。

### 语序、话题或省略差异明显

- 用信息结构和真实语境解释顺序，不只给母语逐词对照。
- 对比“谁已知、谁是新信息、谁被省略”，再让用户改换焦点。
- 避免把自然省略机械补成完整书面句，或把书面顺序强加到口语。

### 敬语、语域、双言或方言连续体

- 在每条材料中记录说话者关系、场合、地区和媒介。
- 先教一个与用户真实场景一致的稳定语域，再展示对比。
- 不把正式书面标准称为唯一“正确语言”，也不把社群变体称为错误。
- 让用户练习识别语域，即使暂时只要求产出其中一种。

### 手语

- 先确认具体手语；手语不是全球通用，也不是周边口语的逐词编码。
- 使用与目标手语相符的可靠视频和社群资料。
- 训练手形、位置、方向、移动、空间结构及面部／身体等非手控标记。
- 让用户提交视频或在可用视觉工具下练习；无法看见动作时不要声称评估准确性。
- 将 gloss 仅作为分析提示，不把 gloss 当作自然手语句子。
- 避免用音频、发音或“母语文字先行”流程替代视觉语言训练。

### 古典、历史、礼仪或主要书面语言

- 先确认目标：阅读原典、礼仪参与、历史语言学、写作还是口头重建。
- 明确采用的时代、文本传统、正字法和发音传统；存在争议时并列而不武断裁决。
- 以短文本、形态解析、句法、语料和翻译比较为主；口语角色扮演仅在目标需要时使用。
- 不虚构“母语者音频”。将重建、教学读音或礼仪读音清楚标记。

### 构造语言

- 优先使用创作者或维护机构的正式语法、词典和规范语料。
- 区分官方形式、社群惯用形式和个人造词。
- 仅在存在真实使用社群时承诺互动材料；否则以规则生成和语料验证为主。

### 低资源、濒危或社群敏感语言

- 优先使用社群认可、学术档案、教育机构或用户提供的资料。
- 核实方言、正字法、说话者身份和记录许可。
- 将无法交叉验证的翻译、发音或语域标为 `needs_confirmation`。
- 不为“课程完整”而补造缺失内容。
- 尊重资料的访问、分享和文化限制；公开可访问不一定代表适合再分发。

## 按学习目标改变优先级

| 目标 | 优先顺序 |
|---|---|
| 日常交流／旅行 | 沟通修复、声音或视觉感知、场景语块、互动、实用语法 |
| 工作／专业 | 场景任务、语域、行业语料、互动和写作准确性 |
| 考试 | 考纲与题型、诊断、目标语法／词汇，同时保留与考试相关的实际技能 |
| 阅读原著 | 文字、形态、句法、高频词、分级到真实文本；口语按需 |
| 写作 | 范文分析、语域、生成、反馈、修订和延迟重写 |
| 影视／播客 | 听辨、连读／变体、可理解输入、片段复述和互动表达 |
| 传承语学习者 | 先诊断口语、听力、识字和语域的不对称，不按零基础处理 |
| 发音专项 | 感知、动作、反馈和新词迁移，不用语法进度代表成果 |

默认实际沟通，但用户目标优先。不要因为方法来源偏口语，就强行把阅读、考试、手语或古典语言改造成同一种课程。

## 多语言组合

默认设一门 `active` 语言，其余为 `maintenance`。安排维护时：

- 将相似语言放在不同时间或不同场景，减少早期混淆。
- 为每种语言使用不同人物、内容主题、颜色或媒介作为检索线索。
- 发现干扰时记录具体形式，不泛称“语言太像所以不能一起学”。
- 根据用户真实时间减少新内容，而不是把所有语言都安排成完整日课。

如果用户明确要求多门同时主攻，说明总练习量和干扰风险后执行，不把默认建议当禁令。

## 资料核实梯度

按内容风险选择证据：

1. 社群／官方规范、权威词典、原始语料或教学机构。
2. 目标变体母语者的可定位原生内容。
3. 正式出版教材或同行评审描述。
4. 多个相互独立、可追溯的可靠例子。
5. 模型推断只能用于提出待核实候选，不能为低资源语言生成确定答案。

记录来源支持的是翻译、发音、语域、频率还是文化用法。一个来源支持其中一项，不自动支持全部。
